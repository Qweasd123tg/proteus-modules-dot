# Повтор пройденных участков

Нужны две локальные Git-копии с зафиксированными объектами Desktop/Extensions, Python 3, Node.js с поддержкой `--permission`, rustc/cargo, локальные совместимые rlib `serde` с derive, `serde_json`, `anyhow`, `markdown` 1.0.0 с его зависимостями и заранее заполненный Cargo-кэш. Поддерживаемый движок Mermaid в репозитории поставляется как исходный JS-модуль: в проверке не вызываются его worker и Desktop. Для независимого повтора backend дополнительно нужен точно указанный в [его инструкции](../author/backend/REPLAY.md) локальный Core checkout `b2c285f` и кэш под соответствующий lock. В этой команде **не исполняется бинарник инструмента**, только его библиотечные тесты. Без `--backend-sdk` этот этап явно пропускается.

    python3 checks/replay.py --desktop "$DESKTOP" --extensions "$EXTENSIONS" \
      --deps "$RUST_DEPS" --markdown-rlib "$MARKDOWN_RLIB" \
      --rustc "$RUSTC" --cargo "$CARGO" --node "$NODE" --backend-sdk "$CACHED_CORE"

[Журнал повторного прогона](replay.log) сохранён с сокращением частных путей; временные имена и длительности могут отличаться. В инструкции запуска не подразумеваются сборка настоящего приложения, установка, полный запуск плагинов или контакт с моделью. Исходный пример не является установочным ZIP. SHA256SUMS относится к публикуемым файлам, а не к внешним зависимостям.
