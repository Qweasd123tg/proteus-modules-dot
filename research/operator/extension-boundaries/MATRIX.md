# Матрица гарантий: 4 границы × 7 независимых вопросов

**Обязательное дополнение:** [OBSERVED-GUARD-LIMITS.md](OBSERVED-GUARD-LIMITS.md) — narrow R57 runtime, accepted limitations, без повышения broad cells до ENFORCED. [Provenance](PROVENANCE.md).
## Значение статусов

- **ENFORCED**: конкретное правило проверено на названном фактическом runtime/config/platform; не переносится на всю категорию.
- **SOURCE** (`source-only`): механизм/ограничение прослежены в закреплённых исходниках; это не executed integration/conformance.
- **DESIGN** (`design-only`): требование к предлагаемому wrapper/connector, ещё не реализованная гарантия.
- **UNKNOWN**: из выбранных evidence нельзя установить требуемую гарантию. Это не доказательство отсутствия механизма.

**В этой широкой матрице нет ENFORCED-ячеек:** ни одна категория целиком не имеет нужного end-to-end acceptance. Это не отменяет существующие passed standalone/actual-binary проверки. В частности, R45 — реальный узкий **контрпример** fidelity, а не сертификация всего процесса или Core. Несколько SOURCE-ячеек описывают установленное ограничение, а не положительную гарантию.

Колонки:

- **T — Trusted local:** доверенное локальное расширение. In-process native код разделяет процесс host; отдельный процесс в режиме Trusted добавляет process boundary, **но не OS confinement**. Broker claims ниже относятся только к process route, не ко всему native коду.
- **R — Restricted process:** существующий явно выбранный Linux Restricted backend, конкретные configured grants и один export. Это не default.
- **G — Data-only guest:** предлагаемый no-I/O evaluator **в обычном process wrapper**. Wasmtime component и Extism ABI различны; сам wrapper/engine остаётся trusted.
- **D — Remote delegation:** предлагаемый outbound connector к отдельно управляемому агенту. Local connector и remote executor — разные владельцы. A2A спецификация не доказывает поведение выбранного сервиса; ACP server не этот connector.

Каждая ячейка имеет тот же ID в [machine-readable matrix](matrix.json). `E01…E12` — точные accepted artifact/section identities из [EVIDENCE.md](../EVIDENCE.md), не новые runtime receipts.

**Общее условие:** operational configuration должна быть реально разрешена/собрана из доверенных sources. Plan/metadata inspection не является safe dynamic initialization, и нет выдуманного lossless config export. Existing R40 checklist — prerequisite оператора, не enforcement этой матрицы. E12.
