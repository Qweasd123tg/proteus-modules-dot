# Первая панель Proteus: одна карточка, две строки

Для первого расширения возьмите [готовый Python-пример из Desktop](https://github.com/Proteus-harness/Proteus-desktop/tree/2307e9c67125bbe66f15ced51317a2dfcc437aa4/examples/catalog/client/demo), а не весь Rust-workspace. Нужны Desktop с поддержкой `protocol: 4` и `manifest.dependencies.core.v1`, а также команда `python3`, доступная Desktop. Это упражнение для проверенного исходного комплекта v4: [в теге публичной alpha.3](https://github.com/Proteus-harness/Proteus-desktop/blob/5e16947f3c777e36df3fbe867d5191e5b02665b9/repositories.json#L16-L21) закреплены расширения с [протоколом v3](https://github.com/Proteus-harness/Proteus-desktop-extensions/blob/b4bc8b99a8c3e6625ce0274a6547354599794f53/PROTOCOL.md#L1). Совместимость этого упражнения с alpha.3 не проверялась. По контракту v4 для этой статичной панели с явным core:false не нужны отдельная сборка Cargo, Core или Git-каталог.

1. Создайте папку **hello-panel**. Скопируйте в неё [`main.py` настоящего примера](https://github.com/Proteus-harness/Proteus-desktop/blob/2307e9c67125bbe66f15ced51317a2dfcc437aa4/examples/catalog/client/demo/main.py) без изменения остальной логики.
2. Сохраните приложенный `view-only/extension.example.json` в самой папке как **extension.json**. Используйте `surfaces.panel`: это боковая панель. `page` относится к странице в настройках, а `content` — к содержимому ответа в чате. Для панели без Core сохраните **оба** поля: `dependencies: {"core": false}` и `required_features: ["manifest.dependencies.core.v1"]`. Иначе зависимость от Core включена по умолчанию. [Подробности](https://github.com/Proteus-harness/Proteus-desktop/blob/2307e9c67125bbe66f15ced51317a2dfcc437aa4/docs/extensions.md#L3-L22).
3. В [строке `"root": …` примера](https://github.com/Proteus-harness/Proteus-desktop/blob/2307e9c67125bbe66f15ced51317a2dfcc437aa4/examples/catalog/client/demo/main.py#L13) замените **только значение** после двоеточия на объект из `view-only/root.expected.json`. Это ровно один `card` с двумя `text` в `children`. Для этого конкретного объекта запись JSON пригодна и как Python-словарь. Не вставляйте его как строку. Никаких обработчиков нажатий добавлять не требуется.
4. Внутри ZIP на первом уровне должны лежать **extension.json** и **main.py**, а не папка `hello-panel/`. README необязателен. По [инструкции Desktop](https://github.com/Proteus-harness/Proteus-desktop/blob/2307e9c67125bbe66f15ced51317a2dfcc437aa4/README.md#L568-L578) выберите ZIP или перетащите его на «Клиент → Расширения». Затем включите расширение и откройте панель «Моя панель». Для этого пути не требуется собирать ни Rust, ни Desktop; имя команды Python должно совпадать с манифестом.
5. **Ручная приёмка:** карточка «Мой список» должна показать «Привет, Proteus!» и «Это локальная панель.» в таком порядке. Проверьте показ панели без Core, закройте и откройте её снова. Если установка не приняла архив, сначала проверьте его верхний уровень и сообщение о манифесте. Если карточки нет, проверьте доступность команды `python3`, включение расширения и зависимость от Core.

Это инструкция сборки вручную. **Приложенный набор — только данные представления и пример манифеста, не готовый ZIP или самостоятельное расширение.** Проверены структура карточки и манифест как данные. Установка, открытие окна, реальный обмен с Desktop и результаты ручной приёмки здесь не проверялись.
