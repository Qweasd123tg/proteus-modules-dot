# list_dir: ошибка перечисления не должна стать частичным успехом

Source-only кандидат для Proteus-modules
`c035142558f0fca43e9772fc0e50ca293abf1531`.

В прямом `list_dir` вызов `entries.flatten()` удаляет ошибки, полученные уже
после открытия каталога. Предложение возвращает существующий `err_result`
вместо успешного неполного списка. Один файл, +14/−1 строка; без новых helper,
retry, cache или полей протокола. Это P3-коррекция обработки ошибок, не
архитектурная переработка и не атомарный снимок файловой системы.
