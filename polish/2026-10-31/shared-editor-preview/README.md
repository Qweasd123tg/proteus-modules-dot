# Единое превью текстовых редакторов

Source-only patch для Proteus-desktop `722b150f2af5c9374081272ca402189666c77bbc`.

Два одинаковых алгоритма в настройках приложения и декларативных полях расширений перенесены в существующий `ui::format::editor_preview`. Новый модуль, состояние, кэш, зависимость или настройка не добавляются. Три изменённых файла, +73 / −116 строк.

Сохранены прежние 8 строк / 2000 Unicode-символов, обрезка конечных пробельных символов только у длинного превью, `None` для короткого текста и ограниченное чтение итератора. Настройки и расширения продолжают передавать rope iterator напрямую; скрытый хвост не материализуется. Рост редактора, раскрытие, фокус, клавиатура и фиксированная высота panel editor не меняются. Действующий дизайн сохранён; это извлечение существующей реализации, не новый UI-примитив.

Общие проверки границ и ограниченного чтения перенесены в `ui::format` один раз. У двух consumers остаются их отличающиеся проверки роста редактора. Повторная матрица превью удалена; новый тестовый стенд не создан.

## Проверка

- Git blob SHA всех трёх исходников совпадают с закреплённой ревизией; SHA256 до/после — в `SOURCES.json`.
- Тело общего алгоритма текстово идентично обоим исходным телам; изменено только имя/видимость функции.
- Строгое применение и обратное применение patch с `--whitespace=error`, совпадение конечных/исходных bytes: пройдено.
- Прямой установленный rustfmt 1.95.0, edition 2024, `skip_children=true`: пройдено.
- Cargo, project scripts, тесты, сборка, CI и нативное окно не запускались. Это не runtime-подтверждённая поставка и не измеренное ускорение.

Применять `shared-editor-preview.patch` к указанной базе. Для подтверждения после переноса достаточно целевых Desktop Rust-тестов общего helper и существующих editor-growth тестов, затем короткой проверки свёрнутого/раскрытого длинного поля в обычных настройках и расширении. Core, Modules и Extensions пересобирать ради этого не требуется; порядок обычной Desktop-сборки описан в upstream BUILDING.md.
