# Desktop: не копировать активную раскладку при запуске

Запуск уже владеет снимком рабочих областей. Внутренние функции восстановления читают активную раскладку по ссылке вместо глубокой копии. Fresh по-прежнему использует новую пустую раскладку и не восстанавливает сохранённого владельца области. Не затрагивает внешнюю копию в Workspace (#451) и порядок расширений (#456).

Проверены оригинальный Desktop `b6a7ec2d8d7e486c8aba01291aa8c89774c4cded` и составной через #456, каждый до и после патча: **72 теста вкладок и 5 сценариев запуска на вариант**. В проверке запуска используется точный код старта, но ответы Core и Codex заданы тестом. Совпали десять записей трассы, в том числе поведение скрытой вкладки, отдельного владельца области, Fresh и ошибок восстановления.

При восстановлении двух панелей патч убирает 12 запросов к аллокатору и 449 запрошенных байт. На тестовой сохранённой раскладке из 72 вкладок убирает 152 запроса и 7 029 байт. Пустая сохранённая раскладка без изменений. Это временные выделения при запуске, не нативное время и не PSS простоя.

В чистой копии Desktop: `git apply --check --whitespace=error -- /путь/source.patch`, затем `git apply -- /путь/source.patch`.
