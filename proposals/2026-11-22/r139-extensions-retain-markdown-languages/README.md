# Markdown: переиспользовать список языков при изменении текста

Когда меняется текст, `Document::render` по-прежнему его разбирает. Если значения и порядок доступных языков совпадают, документ больше не копирует сохранённый список и каждое имя. Смена порядка, регистра или повторов по-прежнему меняет политику и обновляет состояние. Входной список всё ещё создаётся.

## Проверка

- Патч чисто применяется к исходному Extensions `892f627570369ed60d7205eb0d351c753ec4305f` и к точной сборке Extensions со всеми отобранными изменениями через #450. SHA-256 дерева последней до применения: `537ce4840d485c13e32f8b5b456abedd140d9a54709627c2b2bcad94412696df`.
- После применения на сборке через #450: **52/52** модульных теста официального Markdown-пакета. Новый тест меняет текст, подтверждает реальный разбор, сравнивает сериализованный результат со свежим документом и проверяет, что адреса списка и пяти непустых строк не изменились при заново выделенном равном входном списке.
- Stock проверен только на применимость. Интеграционные процессы, Desktop, ускорение и потребление памяти не измерялись.

В чистой копии Extensions выполните `git apply --check --whitespace=error -- /путь/source.patch`, затем `git apply -- /путь/source.patch`. При подготовленном кеше зависимостей:

```sh
CARGO_INCREMENTAL=0 cargo test --release --locked --offline -j1 \
  -p extension-markdown-render --bin markdown-render -- --test-threads=1
```
