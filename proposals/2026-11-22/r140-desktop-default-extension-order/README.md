# Desktop: переиспользовать каталог расширений при порядке по умолчанию

Если пользователь не задавал порядок и идентификаторы в уже полученном каталоге строго возрастают, каталог уже имеет нужный порядок. Возвращаем имеющийся список. Для пользовательского порядка, дублей и несортированных каталогов остаётся прежний путь.

Патч чисто применяется к Desktop `b6a7ec2d8d7e486c8aba01291aa8c89774c4cded` и к точной сборке исходников Desktop через #453. В каждой из этих ревизий отдельно скомпилированы исходная и изменённая функции вместе со штатной логикой настроек и выбора обработчика. Реестр и GPUI заменены тестовыми заглушками. **16/16 целевых проверок**: порядок и первый экземпляр, выбор обработчика и языки, пользовательские и аномальные каталоги, повторное чтение реестра.

На 64 вызовах с отсортированными метаданными 14 штатных расширений, включая создание исходной копии каталога: **320 → 64** обращения за выделением памяти и **50 176 → 7 168 байт** запрошенной памяти. Для пользовательского порядка, несортированного списка и дублей счётчики совпали. Это замер выделений отдельных функций, не время запуска, не RSS приложения и не нативный тест Desktop.

Из чистой рабочей копии Desktop: `git apply --check --whitespace=error -- /путь/source.patch`, затем `git apply -- /путь/source.patch`.
