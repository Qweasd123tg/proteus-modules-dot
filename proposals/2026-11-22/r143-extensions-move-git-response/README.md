# Extensions: использовать данные успешного Git-ответа без копии

Расширение Git после успешного ответа передавало в состояние глубокую копию дерева изменений. Все вызовы либо игнорировали возвращённое значение, либо проверяли успех. Теперь успешный обычный ответ или поле `changes` ответа с `commit` передаётся во владение состоянию, а вызовы получают только признак успеха. Запросы, форматы, обработка ошибок, задержки и Git-поведение не меняются.

Применимость проверена на оригинальной ревизии Extensions `892f627570369ed60d7205eb0d351c753ec4305f` и на точной сборке через #455. На сборке с патчем прошли **52/52 модульных теста** целевого Git-пакета, включая обычный и вложенный ответ, отсутствующее поле, явный null, ошибку HTTP и неизменность состояния при ошибке. Тесты используют локальный подставной сервер, не выполняют Git-команды и не работают с настоящим репозиторием. Память и время не измерялись.

Из чистой копии Extensions: `git apply --check --whitespace=error -- /путь/source.patch`, затем `git apply -- /путь/source.patch`. При готовом офлайн-кэше: `cargo test --release --locked --offline -j1 -p extension-git --bin git -- --test-threads=1`.
