# Desktop: взять в поток запуска только активную область

Перед запуском графики Desktop копировал все сохранённые рабочие области во фоновый поток старта. Ему нужны только активная раскладка и отдельно её владелец. Теперь поток получает только их. Полное восстановление интерфейса, профиль и рабочая папка, режим Attach, fallback и поведение при ошибках не меняются.

Примените **ровно один** вариант: `source.patch` к исходному Desktop `b6a7ec2d8d7e486c8aba01291aa8c89774c4cded`; `source-after458.patch` к точной сборке Desktop через #458. Второй вариант сохраняет сделанное в #458 заимствование раскладки внутри восстановления. Перед применением запустите `git apply --check --whitespace=error -- /путь/patch`.

На обеих ревизиях до и после патча прошли 72 настоящих теста вкладок и 5 сценариев старта с тестовыми ответами на вариант. Совпали 12 трасс, в том числе Attach, другой профиль, скрытая активная вкладка, отдельный владелец, ошибки и Fresh. При 72 неактивных областях подготовка фонового запуска запросила **693 → 25** выделений и **44 908 → 1 503** байта. Это измерение подготовки тестового снимка, не времени нативного запуска и не PSS.
