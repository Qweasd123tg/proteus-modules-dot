# Desktop: читать привязку дочерней сессии без копии JSON

Строки делегирования в чате и проверка, заменяет ли такую строку живой статус, читают `AppSubagentSession` из уже загруженного `subagent_session`. Раньше перед типизированным разбором копировался весь JSON-объект. Теперь Serde читает то же заимствованное значение, не копируя JSON-ключи и строку UUID. Результат по-прежнему владеет своим путём и не удерживает исходные метаданные.

Не меняются допустимые виды инструментов и ID дочернего потока, типизированная проверка UUID и полей, требование абсолютного пути, отказ для несовпадающего UUID/пути у живого статуса, выбор первой подходящей строки и обработка отсутствующей или `null`-привязки. Не добавляются кэш, новый протокол или дополнительные полномочия при переходе в дочерний чат.

База: [Proteus-desktop b6a7ec2d](https://github.com/Proteus-harness/Proteus-desktop/commit/b6a7ec2d8d7e486c8aba01291aa8c89774c4cded). SHA-256 патча: `87c991b9750aed1b0b51249c865e51920131bd41fdb0015132d6e37cf168033b`.

## Проверка

Исходные модули транскрипта и типы Codex взяты из точного Git-архива. Проверено **125** идентичностей зависимостей (имя, версия, источник и контрольная сумма), включая закреплённый `proteus-contracts` и `serde_json 1.0.152` с `preserve_order`. Прямое и обратное применение, `git diff --check` и rustfmt прошли. Единственный изменённый файл совпадает с базой в сводном снимке M100; `git apply --check` прошёл на этом снимке без его изменения. Это отдельный путь от #345, где менялся обход дерева в боковой панели.

Стенд сравнивает результат с исходной реализацией, извлечённой из того же Git-архива. Синтетические страницы строит штатный `Transcript::reset`. В проверках есть повреждённый UUID, неверный или относительный путь, лишние поля, разные представления JSON, совпадающий и конфликтующий статус, несколько возможных совпадений и проверки без привязки.

**1 054** точных сравнения результата разбора и **51 646** сравнений номера строки живого статуса совпали. Штатные тесты модуля транскрипта: **41/41** до правки, **42/42** после.

В последней строке только у одного из 24 инструментов есть соответствующий живой статус. Счётчик суммирует `alloc` и `realloc` на синтетических страницах Linux x86-64. Он не измеряет пиковую память, RSS, отзывчивость или работу всего интерфейса. Время не измерялось.

## Как повторить

`git apply --check /путь/source.patch` из checkout базы. Узкая проверка: `bash verify.sh /путь/Proteus-desktop`. Нужны Bash, Git, Python 3.11+, Rust 1.95 с rustfmt и подготовленный локальный Cargo-кэш для `harness.lock`. Стенд собирается отдельным бинарником без сети в один Cargo job. См. [evidence.log](evidence.log). Полная сборка Desktop и нативное окно GPUI не проверялись.
