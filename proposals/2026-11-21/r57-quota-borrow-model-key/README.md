# Quota: копировать модель только при смене снимка

Бейдж и всплывающее окно Quota раньше при каждом обновлении копировали весь JSON модели, чтобы сравнить его с сохранённым. [Патч](source.patch) сравнивает ссылку на текущий JSON с сохранённым и копирует его только при смене сессии или модели. Ключом по-прежнему служит весь JSON: изменение вложенных параметров обнаруживается даже при том же имени модели. Порядок полей, отсутствующее значение и явный `null` обрабатываются как раньше. Срок жизни снимка, запросы к API, ошибки и виджеты не меняются.

База: [Proteus-desktop-extensions@892f627](https://github.com/Proteus-harness/Proteus-desktop-extensions/commit/892f627570369ed60d7205eb0d351c753ec4305f).

| Стабильная модель, синтетический снимок | Бейдж, байт | Всплывающее окно, байт |
|---|---:|---:|
| `null` | 2 901 → 2 901 | 14 590 → 14 590 |
| Провайдер, имя, подпись | 3 317 → 2 901 | 15 887 → 15 471 |
| Те же поля и вложенные метаданные | 4 347 → 2 901 | 16 917 → 15 471 |

Это байты, запрошенные у аллокатора за один повторный вызов отрисовки с уже загруженными квотами, включая размеры при перераспределении. [Счётчики](measurements.log) совпали в 15 измерениях каждой версии. Задержка, RSS, старт процесса и обновление квот по сети не измерялись.

- Штатный `extension-quota`: **12/12** на базе; **13/13** с патчем в debug и release. Добавлен процессный тест на прежние правила повторного запроса.
- Побайтно совпали **9 обычных кадров** в сценарии с реальным loopback HTTP и **24 кадра** измерительных сборок. Порядок запросов к API совпал. Проверены изменение вложенных данных, эквивалентные обновления, ручное обновление и смена сессии.
- В M100 нет других патчей на Quota; `git apply --check` проходит на канонической композиции. Нативное окно, упаковка и весь workspace не проверялись. [Журнал](checks.log).

Повтор: `python3 reproduce.py путь-к-репозиторию`. Нужны Git, Python 3, Cargo/rustfmt и TCP loopback. Скрипт работает в отдельных временных копиях и не изменяет исходный checkout; при готовом кэше можно задать `CARGO_NET_OFFLINE=true`.
