# Desktop: проверять активную ветку без аллокации для одиночных цепочек

В панели чатов `Row::contains` ищет текущий чат в ветке, чтобы показать его предков и оставить нужный корень в сокращённом списке. Раньше каждый вызов начинал с кучи, даже если ветка состояла из одного листа. Теперь поиск идёт к последнему ребёнку напрямую, а в стек оставляет только остальных братьев. Для листа или цепочки без развилок стек остаётся пустым. Для разветвлённых деревьев поиск по-прежнему итеративный; дополнительной рекурсии нет.

Не меняются порядок обхода, полная проверка ключа, выбор текущего чата, структура веток, фильтр, история и протокол. Codex и Proteus по-прежнему различаются даже с одинаковой строкой идентификатора. Этот путь работает независимо от [#339](https://github.com/Qweasd123tg/proteus-modules-dot/pull/339): там убиралось создание списков корней, здесь облегчается сам поиск по существующей ветке.

База: [Proteus-desktop b6a7ec2d](https://github.com/Proteus-harness/Proteus-desktop/commit/b6a7ec2d8d7e486c8aba01291aa8c89774c4cded). SHA-256 патча: `f35eb1d8d493f4b01e0d5fa047c7b1f33012a6b43d6aeb0774fb0f4dd1d87720`.

## Замер на дереве из штатного кода Desktop

Все деревья построены оригинальным `SessionMarks::arrange` из синтетических сессий. Последняя строка таблицы воспроизводит проверки после первых пяти корней сокращённой папки: 24 корня состоят из пары «родитель, ребёнок», текущий чат вложен в поздний корень.

| Проверка | Запросы аллокатору, до → после | Запрошенные байты, до → после |
|---|---:|---:|
| Лист, есть совпадение | 1 → 0 | 8 → 0 |
| Лист, нет совпадения | 1 → 0 | 8 → 0 |
| Цепочка из 6 строк | 1 → 0 | 8 → 0 |
| 32 ребёнка, нет совпадения | 2 → 1 | 264 → 248 |
| Дерево из 121 строки, нет совпадения | 4 → 2 | 232 → 96 |
| 19 проверок в сокращённой папке | 19 → 0 | 152 → 0 |

Это работа поиска по готовым строкам, а не время отрисовки панели. Счётчик суммирует alloc и realloc, не пик памяти или RSS. Замеры времени на этом стенде не засчитываем: одновременно шли независимые задачи.

## Проверка

- **2 564 168** сравнений с извлечённым исходным методом на деревьях от 1 до 256 строк. Включены листья, цепочки, широкие и смешанные ветви, обе системы ключей, закрепление, архив, фильтр и отсутствующие значения.
- Исходные модули сессий и разговоров: 16/16 тестов; с патчем 17/17. Новый тест проверяет возврат к отложенному соседу после промаха в глубоких потомках и отсутствие совпадения между драйверами.
- **124** внешние идентичности источников, версий и контрольных сумм совпали с Desktop Cargo.lock. Прямое и обратное применение, git diff --check и rustfmt прошли. При применении до или после #258, согласованного #282 и #339 итоговый исходный код побайтно совпал. Журнал: [evidence.log](evidence.log).

## Как повторить

Из checkout базы: `git apply --check /путь/source.patch`, затем при необходимости `git apply /путь/source.patch`. Узкая проверка: `bash verify.sh /путь/Proteus-desktop`. Нужны Git, Bash, Python 3.11+, Rust 1.95.0 с rustfmt и подготовленный локальный кеш для `harness.lock`. Скрипт сравнивает зависимости с исходным lock и собирает отдельный стенд в один Cargo job, без сети. Временная сборка не меняет checkout. Полный Desktop, GPUI, окно, отрисовка и пользовательские данные не проверялись.
