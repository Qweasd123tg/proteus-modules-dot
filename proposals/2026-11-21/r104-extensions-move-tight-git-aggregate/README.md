# Git «Все изменения»: не копировать готовый объединённый diff

Панель объединяет патчи выбранных файлов в строку. Раньше виджет всегда создавал ещё одну копию этой строки. Теперь уже готовый буфер передаётся в существующее поле виджета, если его ёмкость равна длине. Если после объединения есть запас, сохраняется старое копирование: готовый виджет не удерживает лишнюю память.

Формат и порядок полей виджета, вставка перевода строки и сообщения о двоичных, слишком больших или недоступных diff не меняются. Кэш, запросы и их порядок, обновление по ревизии, поведение ошибок, пределы 40 файлов и 4 МиБ с учётом JSON-экранирования и предел Core на один файл прежние. Общее SDK и одиночный diff не затронуты.

## Проверка и применение

Один [source.patch](source.patch), только `packages/git/src/document.rs`, отдельно применяется к upstream Extensions `892f627570369ed60d7205eb0d351c753ec4305f` и к M150 с 16 накладками Extensions до #426 (`b586ea19c61a73456adab28379252d99fd5a8c2ab64a384f7a46adfd4e7b9656`).

[reproduce.py](reproduce.py) проверяет точные исходники, порядок накладок, Cargo.lock, применимость и обратимость патча, штатные release-тесты пакета, живой вывод через синтетический loopback и диагностический замер. Нужны Rust 1.95.0, существующий прогретый офлайн-кеш `CARGO_HOME`, цель `--target` и общий `--lock`. Без `--admit-exclusive` выполняется только предварительная проверка. С флагом: offline locked release, один job, 512 МиБ допуска и 256 МиБ порог остановки. См. `python3 reproduce.py --help`.

Проверены первый показ, повтор из кэша, отдельный diff, смена ревизии и переоткрытие, пустой и отсутствующий текст, нестроковый патч, UTF-8 и экранирование, ответ ошибки и 40 из 41 файлов без чтения последнего. Сохранён штатный тест ограничения объёма с экранированием и вытеснения из кэша.

## Результат

В реальном пути построения виджета для синтетического обычного патча **6 036 Б** буфер действительно перешёл в результат: совпали указатели, а итоговая ёмкость осталась 6 036 Б. Измеренные запросы аллокатору на этом участке: **8 → 7 выделений, 6 422 → 386 Б**, также на повторном показе из того же кэша.

| Вход объединения | Ёмкость готового патча, до → после | Запрошено на построении виджета |
| --- | ---: | ---: |
| Один файл, 6 036 Б | 6 036 → 6 036 Б | 6 422 → 386 Б |
| Два равных фрагмента, 12 072 Б | 12 072 → 12 072 Б | 12 458 → 386 Б |
| Смешанный патч 2 574 Б, входная ёмкость 5 126 Б | 2 574 → 2 574 Б | 2 960 → 2 960 Б |
| Нет текста, 0 Б | 0 → 0 Б | 386 → 386 Б |

Ровно **9 кадров stdout (45 363 Б)** и 58 упорядоченных GET совпали во всех четырёх release-вариантах; операций записи нет. Отдельно совпали 7 диагностических деревьев и результаты пяти повторов на вариант. Штатные тесты: **41 → 42** на upstream, **49 → 50** в композиции.

Замер относится только к построению виджета с объединённым текстом, без самой склейки, HTTP, кэша, списка файлов, сериализации, нативного рендера, времени и RSS. Синтетический патч обычного размера проверяет применимость, но не оценивает частоту таких патчей в реальных проектах. Полный workspace, нативный Desktop и упаковка не проверялись.
