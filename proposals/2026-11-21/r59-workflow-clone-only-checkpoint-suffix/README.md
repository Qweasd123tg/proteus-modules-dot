# coding-workflow: копировать только новые сообщения обычного checkpoint

База: **Proteus-harness/Proteus-modules@9469e3b12529d08b1f4a76882693e2065e842c51**. Локальный commit `7f5e81e3a56e4654e1372d54da58f2c04345afc9`.

При обычном checkpoint workflow возвращает только сообщения после текущего пользовательского сообщения. Раньше перед этим он глубоко копировал всю историю, а затем выбрасывал её префикс. Теперь поиск проходит по исходной истории и копирует только нужный срез. Допустимая полная замена истории по-прежнему копирует и возвращает обе части. Порядок, идентификаторы, отчёты compaction, отсутствие обновления на пустом срезе и сообщения ошибок не меняются.
