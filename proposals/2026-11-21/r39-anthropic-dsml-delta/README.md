# Не сканировать обычную текстовую дельту на DSML-маркеры

В Anthropic-адаптере `DsmlStreamFilter` получает строку для каждого фрагмента ответа. Любой полный или начатый DSML-маркер начинается с `<`. Если у фильтра **нет отложенного префикса** и в новой строке нет `<`, состояние не может измениться. Для обычного текста достаточно вернуть его без изменений; внутри скрытого блока `tool_calls` нужно вернуть пустую строку. Если условие не выполнено, работает исходный парсер. Финализация блока, обработка инструментов и нестриминговые ответы не менялись.

База: `Proteus-harness/Proteus-modules@9469e3b12529d08b1f4a76882693e2065e842c51`. [Патч](candidate.patch) изменяет фильтр и добавляет один тест на реальном потоке событий. Локальный commit кандидата: `593a4f69c021327ddb6a23084b6ec3bc05d0bb11`.

### Что сэкономлено

Оптимизированная сборка самого фильтра, системный Rust-аллокатор, одна нить. По 4096 вызовов в каждом сценарии. Начальное состояние подготовлено до замера, каждый возвращённый результат освобождается сразу. Сумма запрошенных байтов включает realloc; это **не RSS, не пиковая память и не задержка ответа модели**. До/после/после/до дали одинаковые счётчики при повторе каждой версии.

| Входные фрагменты | Выделения, до → после | Запрошено байтов, до → после |
|---|---:|---:|
| Обычные слова, Unicode и перевод строки | 8192 → 4096 | 83 968 → 31 744 |
| Те же фрагменты внутри открытого скрытого блока | 4096 → 0 | 41 984 → 0 |
| Код/HTML с литералом `<` в каждом фрагменте | 8192 → 8192 | 65 536 → 65 536 |
| Чередование текста и разорванных открывающих/закрывающих маркеров | 8192 → 6827 | 86 688 → 71 676 |

### Границы эквивалентности и проверки

На базовом и изменённом исходниках проверено побайтовое равенство **каждой** возвращаемой дельты и результата `finish`, а не только склеенной строки. Корпус: 10 493 тройных разбиения по всем допустимым UTF-8 границам десяти образцов, те же образцы по одному Unicode-символу, 4096 детерминированных трасс по 24 фрагмента. Включены буквальные угловые скобки, Unicode, неполные теги, перенос маркеров через границу дельты, скрытый текст и повторное использование после завершения. Отдельно ожидаемые промежуточные выдачи проверяются вручную заданным эталоном. Если игнорировать отложенный префикс **или** выдать текст внутри скрытого блока, контроль падает. [Результаты](results.log).

22 нативных теста потоковых блоков, начальных событий и классификации ошибок прошли, в том числе новый тест. Это изолированная сборка файлов `stream`, `sanitize`, `response`, `usage` и `errors` с реальными типами contracts; для `reqwest::StatusCode` использован тот же реэкспортируемый тип `http 1.4.0::StatusCode`. [Лог](suite.log). Проверены `cargo fmt --all --check` и `git diff --check`. Workspace целиком, сеть провайдера и упаковка модели не запускались.

### Воспроизведение

Нужны Python 3, Git, Rust 1.95.0 и локальный checkout с указанным коммитом. Проверка берёт файлы через `git show`, применяет патч в отдельном временном каталоге и не меняет checkout. Cargo и зависимости ей не нужны.

```sh
python3 reproduce.py /path/to/Proteus-modules --mutations
```

В отдельной рабочей копии на указанной базе для штатных crate-тестов:

```sh
git apply /path/to/proposal/candidate.patch
cargo test --locked -p model-pack --lib adapters::anthropic::stream
cargo test --locked -p model-pack --lib adapters::anthropic::errors
```
