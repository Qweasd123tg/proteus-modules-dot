# Анализ: не копировать текст инструкции перед форматированием

При показе запроса к модели панель «Анализ» раньше копировала текст каждой инструкции перед сборкой строки с видом и приоритетом. [Патч](source.patch) берёт уже полученную строку по ссылке и форматирует её сразу. Заголовки, порядок, полный текст, переносы, высота и начальное состояние раскрытия прежние. Отсутствующее поле, пустая строка и явный null не смешиваются; формат прочих нестроковых значений не меняется.

| Синтетический сценарий | Запросы выделения | Запрошено байт |
|---|---:|---:|
| Форматирование одного блока, 4 КиБ исходника | 5 → 4 | 8 291 → 4 195 |
| Форматирование трёх блоков, 11,5 КиБ исходника | 15 → 12 | 23 857 → 12 081 |
| Вся карточка M150, один блок | 628 → 627 | 94 657 → 90 561 |
| Вся карточка M150, три блока | 639 → 636 | 173 819 → 162 043 |

[Счётчики](measurements.log) фиксируют пять одинаковых отсчётов System на вариант, включая новый размер при перераспределении. Уходит ровно один временный запрос и размер исходника на каждый непустой текстовый блок. Длины и ёмкости готовых строк не меняются. Это не измерение задержки или RSS.

- Штатный release `extension-analysis`: **12 → 13** тестов на [upstream](https://github.com/Proteus-harness/Proteus-desktop-extensions/commit/892f627570369ed60d7205eb0d351c753ec4305f), **16 → 17** на M150 с дополнениями по #439. Один и тот же патч накладывается и снимается в обеих базах.
- Реальный процесс вернул **15** побайтно одинаковых кадров (267 394 байт) и сделал **11** одинаковых GET к синтетическому loopback на вариант. Покрыты холодное и повторное чтение, Unicode/CRLF, закрытые инструкции, полный JSON и длинная задача, некорректные поля, вывод инструмента и Preview. Нет записей, команд действий, реальных чатов или внешнего сервера. [Проверки](checks.log), [происхождение исполняемых файлов](artifact-receipts.log).

[Воспроизведение](reproduce.py): исходники двух пинов, предыдущие патчи и существующий warm target для offline Cargo 1.95.0; один release job под общим lock, прежние пороги свободного места 512/256 МиБ. GUI, упаковка и полный workspace не проверялись.
