# Desktop: восстановление настроек сохраняет вкладки и отметки чатов на принимающем компьютере

Команда `settings-migration.py export` исключает из `preferences.json` четыре поля, привязанные к машине: `tabs`, `tabs_workspace`, `sessions` и `recent`. Однако `restore` заменял файл целиком. При переносе настроек на уже используемый компьютер пропадали раскладка вкладок, привязка к рабочей папке, названия/закрепления/отметки архива чатов и список недавних папок. **Сами беседы не удалялись**; старый файл настроек попадал в штатную резервную копию.

Патч восстанавливает переносимые поля из архива, а эти четыре берёт только из файла назначения, если он есть. Локальные пути не переписываются под новый home. На чистой машине состояние вкладок не создаётся из архива. Если существующий файл настроек невозможно прочитать как JSON-объект, восстановление останавливается до записи файлов. Экспорт, формат архива, команда обновления storage и механизм резервного копирования не менялись.

**Проверка на реальном CLI с двумя временными home:** база прошла 7 из 9 тестов; упали ровно две новые регрессии. В первой `restore` удалил все четыре поля, во второй перезаписал непригодные локальные настройки вместо остановки. С патчем **9/9**: все семь тестов переноса, в том числе dry-run без записи, перенос пути настроек, сохранившаяся локальная разметка и повторный restore с нулём изменений; плюс два штатных теста portable-ярлыка/launcher. Это проверка Python CLI и локальных файлов, а не запуска GUI. Изменений производительности не заявляется. Для переноса следует закрыть приложение: этот патч не координирует запись настроек с запущенным Desktop.
