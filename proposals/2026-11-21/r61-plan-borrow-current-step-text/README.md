# Plan: читать текст шагов без копии в режиме «По наличию»

Для бейджа режима «По наличию» нужен только текст текущего шага, но раньше расширение копировало строки всех подходящих шагов. [Патч](source.patch) берёт ссылки на строки уже разобранного JSON на время построения бейджа или окна. Строки всё ещё принадлежат снимку, если они получены разбором JSON из строки или нужны кэшу режима «Всегда» после завершения чтения. Дополнительный кэш не добавляется.

Приоритет `effective_args`, правила очистки плана, обработка статусов и выбор текущего шага не меняются. База: [Proteus-desktop-extensions@892f627](https://github.com/Proteus-harness/Proteus-desktop-extensions/commit/892f627570369ed60d7205eb0d351c753ec4305f).

| Синтетические шаги | Текст бейджа, байт | Дерево всплывающего окна, байт |
|---|---:|---:|
| 4 шага, JSON-объект | 693 → 257 | 17 518 → 17 082 |
| 24 шага, JSON-объект | 4 679 → 2 049 | 104 140 → 101 510 |
| 96 шагов, JSON-объект | 18 743 → 8 193 | 415 780 → 405 230 |
| 24 шага, JSON в строке | 21 147 → 21 147 | 120 608 → 120 608 |
| 24 шага, снимок для кэша | 4 679 → 4 679 | 104 140 → 104 140 |

Байты, запрошенные у аллокатора при построении проекции и соответствующего результата, включая перераспределения. Подготовка fixture, сеть, сериализация до отправки и весь процесс не входят в замер. [Счётчики](measurements.log) совпали в пяти отдельных release-процессах каждой версии. Время и RSS не измерялись.

- Штатный `extension-plan`: **17/17** на базе и **18/18** с патчем в debug и release. Новый тест подтверждает заимствование именно исходной строки и владение данными после освобождения ответа в режиме «Всегда».
- **9 обычных кадров** побайтно совпали, включая бейдж, редактирование плана, JSON в строке, очистку, границу хода, режим «Всегда» и предпросмотр. На режим «Всегда» пришёлся один одинаковый loopback GET. Совпали **10** измерительных результатов.
- Других патчей на `packages/plan` в M100 нет. Проверка применения к запечатанному тестовому дереву прошла без изменений. [Проверки](checks.log).

Повтор: `python3 reproduce.py путь-к-репозиторию` (Git, Python 3, Cargo/rustfmt, TCP loopback). При готовом кэше используйте `CARGO_NET_OFFLINE=true`. Входной checkout не изменяется. Нативное окно, упаковка и весь workspace здесь не проверялись.
