# Check active document visibility without allocating a pane list

Desktop base: `b6a7ec2d8d7e486c8aba01291aa8c89774c4cded`. One common production patch, `source.patch`, applies to exact stock and the exact selected source slice through Desktop #442. It adds a short-circuit traversal for the specific question "is this exact ID active in any pane?" and only changes the membership query inside `Workspace::document_visible`. The ordered `visible()` API and all other callers stay as they were. The predicate tests `leaf.active`, not general tab ownership. Both source tiers use the same implementation without requiring #267.

Settings still gates the layout query first. Only then can the matching **live** document and exact entity pass. `document_current`, parked documents, canonical/raw alias handling, terminal memo and connection guard are unmodified. The patch adds no state, cache, dependency, authority or route.
