# Desktop: отсекать лишние строки истории до обхода их JSON

Когда окно уже содержит 200 строк и в него поступает следующая страница из 50, прежний подсчёт объёма обходил все 250 строк и ещё раз обходил 50 строк на вытеснение. Теперь сначала выбирается тот же диапазон, который разрешают лимит строк и видимая область. Лимит объёма затем проверяется на его содержимом. В состоянии открытого окна не появляется счётчик, кэш или диагностический код.

Правка только в `HistoryWindow::trim` для истории Core. Границы по числу и объёму, минимальная страница, защита видимых строк, неразрезаемая крупная строка, порядок строк и возвращаемые splice-изменения сохраняются. Путь Codex, траектория запроса и правило для дробного поиска не меняются.

База: [Proteus-desktop b6a7ec2d](https://github.com/Proteus-harness/Proteus-desktop/commit/b6a7ec2d8d7e486c8aba01291aa8c89774c4cded). SHA-256 патча: `87c96e53a64f765f60599998ffb0e9d0374b56e60e5f1bfc1827259d458e32ea`.

## Проверка

- На точном M150: **70/70** узких тестов до и после; на чистом b6a7ec2d: **61/61** в обеих версиях. Диагностические трассы решений совпали побайтно: **396** сочетаний длины окна, направления, положения видимой области и большой строки; дополнительные переходы настоящего редьюсера сохраняют ключи, глобальный логический anchor, диапазоны, splice-изменения и итоговый бюджет.
- Отдельно проверены лимит только по байтам, крупная защищённая строка, видимая область, пересекающая границу вытеснения, и контрольные пути Codex. Результаты подсчёта и ограничения: [DIAGNOSTIC.md](DIAGNOSTIC.md), числовой журнал: [evidence.log](evidence.log).
- Сверены **125** точных идентичностей зависимостей, SHA полного исходного дерева M150 и Cargo.lock до/после. Прямое и обратное применение, `git diff --check` и rustfmt прошли. Три проверки, которым нужен GPUI, исключены из этого прогона; окно, реальные пиксели, время и RSS не измерялись.

## Как повторить

Из checkout базы: `git apply --check /путь/source.patch`. Повторить диагностический стенд: `bash verify.sh /путь/Proteus-desktop`. Для проверки запечатанного сводного Desktop добавьте `/путь/desktop /путь/source-seal.json`. Нужны Bash, Git, Python 3.11+, Rust 1.95 с rustfmt и локальный Cargo-кэш для `harness.lock`. Стенд собирается без сети, в один Cargo job и во временной копии.
