# SDK: не копировать превью перед формированием подписей сессий

Панели «Расход» и «Анализ» строят подписи по каталогу сессий. Раньше SDK сначала создавал временную строку из первых 60 символов превью, а затем собирал отдельную подпись. [Патч](source.patch) берёт тот же UTF-8 срез прямо из исходного превью. Подписи, граница в 60 Unicode-символов, пробелы, порядок строк, счётчики сообщений и выбор при дубликатах не изменились.

| Измеренный участок | Запросы выделения | Запрошено байт |
|---|---:|---:|
| Форматирование 20 подписей | 120 → 60 | 10 310 → 5 830 |
| Форматирование 50 подписей | 300 → 150 | 25 775 → 14 575 |
| Весь тёплый селектор M150, 20 строк | 301 → 241 | 25 655 → 21 175 |
| Весь тёплый селектор M150, 50 строк | 721 → 571 | 61 972 → 50 772 |

[Счётчики](measurements.log) относятся к пяти одинаковым отсчётам System на вариант и включают новый размер при перераспределении. Суммарная длина и ёмкость итоговых подписей не изменились. TTL, кэш, число запросов, доступ и выбор сессии прежние. Это не измерение задержки или RSS.

- Release: SDK **60 → 61** тест на [upstream](https://github.com/Proteus-harness/Proteus-desktop-extensions/commit/892f627570369ed60d7205eb0d351c753ec4305f) и **70 → 71** на точном составе M150 через #437. Usage: **12/12** и **17/17** с патчем и без. Один патч накладывается и снимается в обеих базах.
- Настоящие release-процессы Usage и Analysis вместе вернули **30** побайтно одинаковых кадров (164 848 байт) и сделали **24** одинаковых упорядоченных GET к синтетическому loopback на вариант, без записей или внешнего сервера. Покрыты холодный и тёплый каталоги, 59/60/61 символ, составные Unicode-последовательности, пустые и некорректные значения, дубликаты выбранного ID, переключение на синтетическую сессию и Preview. [Проверки](checks.log) и [происхождение исполняемых файлов](artifact-receipts.log).

[Воспроизведение](reproduce.py): локальные исходники двух баз, список предыдущих патчей и существующий target для offline Cargo 1.95.0. Один release job под общим lock; прежние пороги 512/256 МиБ. GUI, полный workspace и упаковка не проверялись.
