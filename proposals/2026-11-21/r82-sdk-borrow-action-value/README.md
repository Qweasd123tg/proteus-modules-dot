# SDK Extensions: не копировать значение входящего действия

[Патч](source.patch) передаёт в `Extension::action` ссылку на `value` из уже разобранного сообщения. Раньше SDK клонировал всё поле, хотя callback использует его только на время вызова. Это убирает временную копию таких данных, как очередная полная версия черновика Git, строки поиска и вложенные значения элементов управления.

Сохраняются маршрут, `sequence`, порядок callback и обработки ошибок. Отсутствующее поле всё так же даёт null, явный null и числовые значения не меняются. После ошибки остаётся прежнее представление. Нет изменений протокола, ограничений, прав или времени хранения данных: Git по-прежнему держит собственный черновик, а SDK не удерживает новый буфер. Это не изменение отправки badge, принятого `command_result` или очереди stdin.

| Синтетическое действие, точная база | Запросов выделения | Запрошено байт |
|---|---:|---:|
| Поле отсутствует, null или число (каждый контроль) | 11 → 11 | 414 → 414 |
| Короткая строка поиска | 12 → 11 | 427 → 414 |
| Строка 16 КиБ | 12 → 11 | 16 798 → 414 |
| Вложенное значение из 32 записей | 272 → 11 | 31 500 → 414 |

[Счётчики](measurements.log) охватывают успешные выделения и перераспределения на одном потоке при вызове реального обработчика уже разобранного сообщения с простым callback. Пять точных повторов каждого плеча. Адрес исходной строки виден в callback новой версии; прежняя версия передавала другой буфер. Подготовка fixture, разбор JSON, сериализация вывода и работа приложения за пределами изолированного обработчика не измерялись. Это не измерение RSS или задержки.

- На накопительном стеке тот же эффект: строка 16 КиБ **16 667 → 283 Б** (10 → 9 запросов), вложенное значение **31 369 → 283 Б** (270 → 9), скалярные контроли без изменений (9 запросов, 283 Б). Абсолютная база ниже, в неё уже входит сокращение очистки сессий #402.
- Побайтно совпали **55 обычных кадров** на всех четырёх плечах: Mode 26, Model 24, Git 5. Два окна Mode/Model, перенос, принятие и отказ остались прежними. Реальный Git получил четыре правки только синтетического черновика (включая многострочный текст), сохранил байты и sequence 0–4. Его стенд разрешал только три GET на loopback, без отправки коммита или записи в репозиторий.
- SDK release: **60 → 61** и **69 → 70** модульных тестов, по одному doc-тесту. Mode: 4/4 на обеих базах; Model: 10/10 и 11/11; Git: 41/41 и 44/44. Отдельно повторены обработка ошибок/паники, borrowed buffer, отсутствие/null, sequence и прежнее дерево после отказа.
- [Сборочные квитанции](artifact-receipts.log) фиксируют четыре точных дерева, наложения, lock-файл и инструменты. **36 свежих** артефактов Cargo JSON и четыре сверенные повторные ссылки на SDK того же плеча. Хеши фактически выбранных исполняемых файлов проверены до и после запуска.

База: [Proteus-desktop-extensions@892f627](https://github.com/Proteus-harness/Proteus-desktop-extensions/commit/892f627570369ed60d7205eb0d351c753ec4305f). Прямое/обратное применение и оба порядка поверх точного M150 + #394 + #395 + #397 + #399 + #402 + #404 проверены отдельно. [Проверки](checks.log).

Нужен явный `CARGO_HOME` с доступными офлайн зависимостями. Без флага допуска только проверка входов. Один Cargo job, locked/offline, стартовый порог 512 МиБ и остановка ниже 256 МиБ на обоих томах. Исходный checkout не изменяется. Полный workspace, упаковка и нативное окно не проверялись.
