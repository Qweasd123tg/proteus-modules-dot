# Git Changes: подсказка для коммита без списков всех файлов

[Патч](source.patch) сохраняет правило панели Git: предложить сообщение для единственного файла в индексе, а если индекс пуст, для единственного отслеживаемого изменения. Раньше при каждом вызове ради этой проверки собирались два вектора ссылок на файлы. Теперь при втором подходящем файле результат уже известен. Когда файл в индексе один, список отслеживаемых изменений не строится. Проверка конфликтов и выбор глагола остаются прежними.

База: [Proteus-desktop-extensions@892f627](https://github.com/Proteus-harness/Proteus-desktop-extensions/commit/892f627570369ed60d7205eb0d351c753ec4305f). Меняется только `packages/git/src/model.rs`. Построение дерева, протокол, подтверждения, Git-команды и их обработчики не меняются.

## Сколько работы убрано

Байты, запрошенные у аллокатора за один вызов на готовом синтетическом снимке, включая размеры при перераспределении:

| Файлы | Подсказка, до → после | Построение редактора с пустым текстом, до → после |
|---|---:|---:|
| 32 изменены, ни одного в индексе | 480 → 0 | 19 273 → 18 313 |
| 512 изменены, один в индексе | 8 240 → 48 | 34 633 → 18 249 |
| 2 000 изменены, ни одного в индексе | 32 736 → 0 | 83 785 → 18 313 |
| 2 000 изменены, все в индексе | 65 472 → 0 | 149 233 → 18 289 |

Для целой раскрытой панели эффект меньше: при 32 изменённых файлах в индексе 988 875 → 986 955 байт (−0,19%). Выигрыш относится к выбору подсказки, не к отрисовке всех файлов. Когда все файлы новые и индекс пуст, обе версии не выделяют память на выбор. [Сырые счётчики](measurements.log) совпали в пяти отдельных release-процессах каждой версии. Не измерялись время, RSS или нативное окно.

Штатный пакет Git: **41/41** на базе, **42/42** с патчем в debug и release. Сравнены **2 801** последовательность до четырёх файлов из семи вариантов, включая конфликт, переименование и неизвестный статус. **24 кадра** обычного процесса Git с локальным тестовым HTTP совпали побайтно: поля ввода, пробельный и явный текст, сворачивание и раскрытие редактора, отказ при конфликте и порядок чтений. Проверены оба порядка наложения с предложениями #283 и #319; совмещённые тесты Git и SDK прошли. #291, #309 и #322 меняют другие пути. [Журнал проверок](checks.log).

Повтор: `python3 reproduce.py /путь/к/Proteus-desktop-extensions`. Нужны Git, Python 3, Cargo/rustfmt и TCP loopback. Скрипт работает во временных копиях, не меняет входной checkout; при готовом кэше можно задать `CARGO_NET_OFFLINE=true`. Обычные бинарники проверяются до вставки счётчика в отдельную измерительную сборку. Полный workspace и упаковка не проверялись.
