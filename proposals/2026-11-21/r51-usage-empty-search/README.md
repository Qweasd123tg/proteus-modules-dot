# Usage: пустой поиск без копий полей каждого запроса

Страница «Расход» по умолчанию открывается без поискового запроса. Раньше фильтр всё равно склеивал ID запроса, ID хода, провайдера и модель, приводил строку к нижнему регистру и выбрасывал её для каждой записи. [Патч](source.patch) сразу собирает записи, прошедшие фильтры статуса, если в запросе нет слов. При введённом запросе приводит его к нижнему регистру только один раз на построение вида, причём не делает и этого, если ни одна запись не прошла фильтры статуса.

База: [Proteus-desktop-extensions@892f627](https://github.com/Proteus-harness/Proteus-desktop-extensions/commit/892f627570369ed60d7205eb0d351c753ec4305f). Разделение на слова, приведение к нижнему регистру Unicode, склейка полей для непустого запроса и правило «каждое слово должно встретиться» остаются прежними. Патч не меняет HTTP, кэш, фильтры статуса/периода, сортировку и обработку неизвестных значений, лимиты и формат виджетов.

## Замеры

Выборка из заранее построенного журнала. В [сырых данных](measurements.log) раздельно показаны аллокации внутри фильтра и внутри полного построения страницы Usage. Счётчик включает запрошенные размеры и при `realloc`. Подготовка fixture, HTTP, запись JSON, Desktop, RSS и задержка не измерялись. ## Проверки

- Штатный пакет Usage, Rust 1.95.0, `cargo test --locked -p extension-usage`: **12/12** на базе, **13/13** с патчем, в debug и release. Новая проверка включает Unicode-пробелы, греческую конечную сигму, раскрытие латинской İ и прежние фильтры статуса.
- Обычные release-процессы при одинаковом локальном HTTP fixture вернули **14 побайтно одинаковых кадров**. Проверены открытие страницы, пустой поиск, Unicode и несколько слов, отсутствие совпадений, сортировка, переход страницы и «Последний ход». Последовательность HTTP-запросов одинакова (/sessions, /usage). Дополнительно совпали все 15 синтетических деревьев с ID отфильтрованных запросов.
- Дедупликация: #291 индексирует номер хода, #309 разделяет владение Analytics JSON, #203 исправляет выбор последнего хода, #215 меняет агрегацию по моделям, #192 оптимизирует фильтрацию Desktop picker. Их изменения не убирают работу в `report::filtered`. Совмещение этого патча с #291 и #309 в прямом и обратном порядке даёт одинаковое дерево; совместные тесты Usage, Analysis и SDK прошли. [Проверки](checks.log).

Повтор: `python3 reproduce.py /path/to/Proteus-desktop-extensions` (Git, Python 3, Rust/Cargo/rustfmt и TCP loopback). Скрипт не меняет входной checkout и использует отдельные Cargo target для базы и кандидата. При готовом кэше можно задать `CARGO_NET_OFFLINE=true`. Полный workspace, нативное окно и упаковка не проверялись.
