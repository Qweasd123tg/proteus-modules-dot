# Context: построение карты без второго списка категорий

Карта окна контекста раньше собирала отдельный список ссылок на категории, заново читала число токенов и несколько раз копировала подписи, цвета и готовые строки. [Патч](source.patch) сохраняет число токенов сразу в списке сегментов, масштабирует их в прежнем порядке и переносит готовые строки в JSON. Статические подписи и цвета не копируются до построения JSON.

Сохраняются пропуск категорий кэша провайдера и невалидных чисел, порядок и цвета сегментов, масштабирование, распределение 200 клеток, резерв автокомпакта, порядок полей и правила чтения API. Кэш не меняется. База: [Proteus-desktop-extensions@892f627](https://github.com/Proteus-harness/Proteus-desktop-extensions/commit/892f627570369ed60d7205eb0d351c753ec4305f).

| Синтетический профиль | Карта, байт | Тело всплывающего окна, байт |
|---|---:|---:|
| Окно не занято, категории присутствуют | 3 123 → 1 767 | 49 985 → 48 629 |
| Известен расход, категорий нет | 1 597 → 965 | 47 748 → 47 116 |
| 8 известных категорий, свободное место и резерв | 15 684 → 9 232 | 68 580 → 62 128 (−9,4%) |
| 16 смешанных категорий, свободное место и резерв | 28 640 → 16 990 | 87 422 → 75 772 (−13,3%) |

В таблице суммарные байты, запрошенные у аллокатора за один вызов построителя, включая перераспределения. Данные уже загружены; сериализация готового дерева не включена. Результат совпал в пяти release-процессах на каждую версию. Это не замеры скорости и RSS. [Счётчики](measurements.log).

- Штатный `extension-context`: **3/3** на базе, **4/4** с патчем в debug и release. Новый тест фиксирует порядок цветов и распределение равных остатков после исключения категорий.
- Побайтно совпали **5** обычных кадров панели и предпросмотра и **10** измерительных деревьев. Совпал порядок HTTP-чтений. На запечатанном M100 патч проходит `git apply --check` без изменений дерева. [Журнал](checks.log).

Повтор: `python3 reproduce.py путь-к-репозиторию` (Git, Python 3, Cargo/rustfmt, TCP loopback). При готовом кэше можно задать `CARGO_NET_OFFLINE=true`. Скрипт не меняет входной checkout. Полный workspace, нативное окно и упаковка не проверялись.
