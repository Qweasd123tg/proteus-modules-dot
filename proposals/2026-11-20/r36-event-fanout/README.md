# Core: передать исходное событие последнему получателю

База: `Proteus-harness/Proteus-core@32e56ecb4cc6da324c60dd6ae2da78f3b7e46e7f`. Изменён один внутренний путь: `FanoutEventSink::append` вызывает предыдущих получателей с копиями события, а последнего с уже принадлежащим ему оригиналом. В app-server это связка из двух получателей: фильтруемый JSONL-журнал, затем обновление состояния приложения. Формат журнала, набор событий и политика фильтрации не меняются.

Сохраняются последовательность вызовов, попытка доставки каждому получателю после ошибки и возврат самой первой ошибки. Для нуля получателей результат остался успешным. Новый тест проверяет полное равенство envelope, порядок и первую ошибку для 31 комбинации (0–4 получателя, все маски отказов). Тест прошёл, как и семь смежных тестов событий app-server. `cargo fmt --all --check`, `git diff --check` прошли; полный workspace не запускался.

**Замер**: два исходных модуля (stock/patch) в одном оптимизированном пробнике, один и тот же реальный тип `EventEnvelope`, одинаковые async-получатели без I/O, вход подготовлен до счётчика. На каждую из 16 нагрузок порядок ABBA. Все вызовы alloc/alloc_zeroed/realloc и запрошенные байты во время вызова (включая упакованные futures), не RSS и не задержка UI. Для двух получателей:

| Событие | Запросы, было → стало | Байты, было → стало |
|---|---:|---:|
| Пустая строка | 3 → 3 | 1 400 → 1 408 |
| Строка 32 Б | 5 → 4 | 1 464 → 1 440 |
| Строка 1 МиБ | 5 → 4 | 2 098 552 → 1 049 984 |
| ToolFinished с 128 вложенными строками метаданных | 2 319 → 1 161 | 155 592 → 78 504 |

Для пустого события или нуля получателей размер future в этом toolchain вырос на 8 Б. Копии для остальных получателей, запись JSONL и преобразования downstream не устранены. Подробности в `allocations.csv`.

Воспроизведение из Core на указанном коммите (Rust 1.95.0, Linux/lld, стандартный test target). Для семи смежных тестов нужны обычные process fixtures Core.
```sh
git apply "$PROPOSAL/source.patch"
cargo fmt --all --check && git diff --check
cargo test --locked -p proteus-core --lib core::event_store::
cargo test --locked -p proteus-core --lib app_server::events::
python3 "$PROPOSAL/probe.py" . "${CARGO_TARGET_DIR:-target}/debug/deps" /tmp/fanout-probe
```
