# Холодное возобновление: парное сравнение в release

Один и тот же оптимизированный Core R24 `fb0b180a778e`, два release JSONL worker (базовый `cf999371f6e5` и кандидат `terminal-read.patch`). Linux, модель не вызывалась. Для каждого размера один набор байтов журнала, те же путь/inode/mtime/ctime и точный checkpoint; на каждый запуск новый Core + worker. В конфиге постоянный путь к worker, в стенде перед запуском переключается только локальная ссылка на соответствующий бинарник. Чередование вариантов ABBA, порядок наличия display HEAD меняется между раундами. Кэши ОС не сбрасывались. Измеряется время от запуска до коррелированного ACK по stdout, не Desktop и не первый токен. Полные SHA-256 бинарников в manifest.

| Синтетические записи истории | Display HEAD | База → патч, медиана, мс | Медиана парных разниц, мс [мин, макс] |
|---:|---|---:|---:|
| 5000 | Есть | 181,2 → 168,7 | −16,0 [−32,9; +5,9] |
| 5000 | Нет | 467,0 → 391,2 | −55,3 [−168,8; +81,8] |
| 1050 | Есть | 85,1 → 80,6 | −2,6 [−21,8; +3,5] |
| 1050 | Нет | 135,4 → 138,6 | −1,7 [−209,2; +204,2] |

8 пар на каждую строку. Меньшее время на большой фикстуре видно в медиане, но не во всех парах. Для 1050 выигрыш не установлен. Отсутствие display HEAD означает удалённый заголовок и сохранённые остальные страницы, не пустой дисковый кэш. Это одна тестовая машина; конкурирующую активность ОС не изолировали. Тестовый счётчик декодирований (16 → 8) не оценка RAM, дискового I/O или результата в Desktop. R27 использовал debug Core и не служит базой для release-цифр.

Воспроизведение: задайте четыре переменные окружения из README; добавьте каталог с R27 в `PYTHONPATH`. Используйте один и тот же release Core с R24 в обоих аргументах `--stock-cli` и `--patch-cli`. Смена worker через `--stock-worker` / `--patch-worker`. Запуск:
```sh
python3 -B compare.py --stock-cli "$PROTEUS_PEER_CLI" --patch-cli "$PROTEUS_PEER_CLI" \
  --stock-worker "$PROTEUS_TEST_SESSION_STORAGE_MODULE" --patch-worker /path/to/patched/worker \
  --rows 5000 --width 175 --reps 8 > new-pairs.jsonl
python3 -B compare.py --summarize new-pairs.jsonl
```
