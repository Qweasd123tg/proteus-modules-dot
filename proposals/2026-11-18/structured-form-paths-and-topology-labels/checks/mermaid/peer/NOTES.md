# Independent peer gate for ordinary quoted Mermaid node text

The replay extracts and compiles the two real Rust label helpers and checks that the complete diagnostic formatter body is byte-identical apart from exactly five replacements of the helper call. No Mermaid renderer, browser, service, extension, live graph or real profile was run.

The independent oracle is purposely restricted. In 11.12.0, [Diagram.ts](https://github.com/mermaid-js/mermaid/blob/0116b272b4b558f60ec292fb994148956287eaa1/packages/mermaid/src/Diagram.ts#L15-L23) preprocesses entities before parsing. [utils.ts](https://github.com/mermaid-js/mermaid/blob/0116b272b4b558f60ec292fb994148956287eaa1/packages/mermaid/src/utils.ts#L896-L928) first performs two legacy full-line substitutions, then recognizes ASCII word entity codes. The [lexer](https://github.com/mermaid-js/mermaid/blob/0116b272b4b558f60ec292fb994148956287eaa1/packages/mermaid/src/diagrams/flowchart/parser/flow.jison#L82-L87) returns STR for a run without ASCII double quote; the [grammar](https://github.com/mermaid-js/mermaid/blob/0116b272b4b558f60ec292fb994148956287eaa1/packages/mermaid/src/diagrams/flowchart/parser/flow.jison#L504-L511) consumes the token as ordinary string data. In particular a backslash is not an escape in STR. [Official flowchart examples](https://github.com/mermaid-js/mermaid/blob/0116b272b4b558f60ec292fb994148956287eaa1/packages/mermaid/src/docs/syntax/flowchart.md#L874-L883) explicitly demonstrate #quot; and explain #35;. 

The oracle implements only benign ordinary named/decimal character references in inert labels, inspects the one-ordinary-token contract, and checks the original text. No other syntax is tested or generated. It does not establish pixel rendering or behavior of arbitrary inputs. A source-only check separately confirms edge formatting is unchanged. Positives include Research "Alpha", a Windows-like label with one backslash and Unicode. Negative checks include intact entity spelling, bare ampersands and a familiar language tag embedded in plain text ("Status style:C#"). The latter distinguishes a change which introduced unnecessary hash encoding.
