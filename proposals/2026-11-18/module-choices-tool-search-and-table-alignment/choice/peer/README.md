# Independent retained-callback audit

Cuts the actual multiselect function, effective-value selection and serde DTO declaration from the supplied sources. A fake layout collects labels/checkboxes and retains their real callback closures; it records emitted JSON without saving anything. An independent membership/order oracle checks each of 8,320 callbacks, not just a hash. Includes repeated actions against one snapshot, duplicate option values with different titles, mixed numeric and string values, nested JSON, unknown saved choices, malformed non-array values, defaults and no selection.

For allocation counting, the global Rust allocator counts calls and all requested bytes only between beginning and returning from constructing the collected widget. It does not count setup, measure RSS/peak/live memory or time a real frame. This second fixture uses nested JSON values in addition to the author's ordinary numeric grid. Relative improvement should be remeasured in any real application; unrelated rendering, prep, copy-on-selection or existing membership comparisons are not eliminated.
