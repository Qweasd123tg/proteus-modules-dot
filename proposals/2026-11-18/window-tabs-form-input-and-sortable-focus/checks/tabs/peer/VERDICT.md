The app-level drag source, the layout.contains eligibility test in frame, drop payload, and callback that moves a tab are unchanged. Each set of bar callbacks now uses its Workspace's arrangement. The holder contains ordinary owned strings, numbers and geometry; it does not retain the Workspace, a Window or a closure.

**Independent native replay** (peer.py, peer.rs.in, peer.log): exact pure arrangement functions from each checkout with stand-ins for geometry, windows, App.drag and layout.contains. One App, two layouts with distinct source IDs but the same pane number and common sibling ID; four coordinates, two foreign sibling locations, B normal paint before vs after A hover. **13/16 incorrect A drop targets before, 0/16 after**. It also demonstrates that 64 record-only idle entries can remain in a living Workspace; this patch is not a fixed-size cache or cleanup on each tab close.
