# Повторно использовать уже валидированный короткий суффикс

Дополнительный [патч Core](retained-suffix.patch) поверх двух патчей #220, без зависимости от seek в worker. Строгое чтение до проверенной границы, затем каноническое чтение после неё через действующий RPC; ошибка после границы по-прежнему останавливает публикацию. Короткий хвост, пока он хранится, проверяется тем же валидатором, затраты ограничены по счёту (до 16 записей) и сериализованному размеру (до 256 КиБ). Это не лимит RSS. После превышения порога буфер освобождается, используется существующий потоковый путь. Для 1–16 записей, которые затем превысили 256 КиБ суммарно, выравнивание у курсора может стоить одного дополнительного RPC; для хвостов больше 16 записей RPC-путь прежний. Не сохраняет историю между ходами.

На повторном запуске проекции настоящего синтетического Dogfood-журнала (21 старый + 6 новых фактов, 2 000 строк архива, release worker из #219) проверены равные результаты независимой полной проекции. Шесть чередующихся пар: RPC ReadRecords **6→2**, получено записей **57→27**, JSONL-ответы этого RPC **1 209 090→939 109 байт**, медиана времени проекции **142,75→101,29 мс**; быстрее во всех шести парах. Медиана отношения по парам −33,2%; отдельно CPU worker 107,58→63,43 мс, Core CPU без устойчивого выигрыша. Это проекция, не весь ход, и не 50k. Не складывать с результатом seek: после seek старые строки внутри хвостовых RPC стоят уже иначе. Сырые [пары](pairs.csv), [итог](pairs-summary.log) и [стенд](real.rs).

58/58 фокусных нативных тестов [в логе](native-tests.log). Дополнительные независимые контроли: пересечение порогов ±1 байт, поздняя ошибка страницы/иного snapshot, логический reset и конкурентное обновление источника. Буфер использует уже строго проверенные bytes; он не может обнаружить ошибку **устранённого** более позднего физического повторного чтения. Внешний blob проверяется при канонической загрузке; старая схема также не давала атомарной гарантии его доступности вплоть до публикации. Не считать кандидата готовым к переносу только на основе компонентного теста.
