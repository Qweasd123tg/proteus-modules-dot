# Как повторить

Патчи применяются к закреплённым исходникам отдельно от этого репозитория. Не запускайте команды в своей рабочей копии с несохранёнными изменениями: используйте временную копию исходного дерева для каждого проекта. Понадобятся Python 3 и совместимый стабильный rustc (проверялся 1.95.0). В примерах `$D` / `$M` — исходные Desktop / Modules, `$P` / `$Q` — их копии с патчами. Команды запускаются из каталога предложения. Файлы в каталогах `checks` — стенды, они не запускают приложение.

- **Вставка:** `python3 checks/paste/check_paste.py "$D" "$P"`. До исправления стенд ожидает известное число расхождений и выводит оба протокола.
- **Настройки:** [инструкции и зависимости](compact/README.md).
- **Цветовая тема:** `python3 checks/theme/check.py "$D" "$D"` (ожидается ненулевой код на градиенте), затем `python3 checks/theme/check.py "$D" "$P"` (оба набора 18/18).
- **Строки списка:** `python3 checks/list/assemble.py "$Q" /tmp/proteus-list-rows.rs`, `rustc --edition=2024 -O /tmp/proteus-list-rows.rs -o /tmp/proteus-list-rows`, `/tmp/proteus-list-rows`. То же с `"$M"` оставляет текст верным, но не проходит лимит выделений памяти.
- **Частичная Markdown-таблица:** `python3 checks/markdown/verify.py "$D" "$P"`, с Rust и Pandoc (проверялся 3.1.11.1). Отдельно: `python3 checks/markdown/native_boundaries.py "$P" /path/to/markdown-rs-1.0.0/src/construct/gfm_table.rs` проверяет [четыре функции закреплённого лексера](https://github.com/wooorm/markdown-rs/blob/1506572f9b406431402928f3a8b3df0b4ae2d8f5/src/construct/gfm_table.rs). [Протокол](markdown/independent-boundaries.txt).
- **Смена вида поля:** [диагностика](../diagnostics/same-id-search.md); исправление не заявлено.

Малые стенды проверяют отдельные операции настоящих функций; место, где заменены оконные объекты или внешняя зависимость, указано в отчёте. Счётчики памяти — количество вызовов и суммарно запрошенные байты на конкретных наборах; это не пиковая память и не измерение кадров или времени.
