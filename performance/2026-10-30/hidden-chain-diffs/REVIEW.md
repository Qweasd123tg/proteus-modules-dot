# Независимый source review

Подтверждён отдельный случай скрытой родительской цепочки, а не повтор исправления collapsed-row. Источники сверены с Git blob IDs.

Кандидат вычисляет состояние группы до фильтра expanded: даже первый раскрытый участник в середине получает состояние настоящего head. Длинная folded-цепочка разбирается один раз, короткие имеют максимум два участника. Сохраняются open/moving и актуализация effective_args перед повторным показом. Retained состояния и Copy не меняются. По исходникам блокеров не найдено; это не typecheck и не native-проверка.

Добавленные тесты проверяют топологию через traversal harness, а не фактический UI guard. Они не запускались. Анимация, первый кадр после открытия и фактические clipboard bytes требуют отдельной разрешённой native-проверки.
