# Не подготавливать скрытый diff внутри свёрнутой цепочки

Source-only кандидат для Proteus-desktop `a28cc7f507424a570e86dc44230ee323156fdf6c`.

Если раскрыть apply_patch внутри цепочки инструментов, затем свернуть саму цепочку, флаг раскрытия строки сохраняется. Сейчас каждый render чата сравнивает весь неизменившийся patch через set_patch, хотя тела строк уже скрыты; изменившийся patch также копируется, разбирается и подсвечивается. Это отдельный случай от уже исправленного сворачивания самой строки.

Патч пропускает подготовку только для полностью закрытой неподвижной compact-цепочки. Открытие, закрывающая анимация и её разворот сохраняют прежний путь; повторное открытие подготавливает актуальные effective_args до построения тела. Состояние строк и DiffView не очищается, Copy не меняется. Граница каждой длинной цепочки вычисляется один раз за проход; дополнительного долговременного кэша нет.

При H удерживаемых строках и P байтах неизменившихся скрытых patches остаётся O(H) проход, но исчезает Θ(P) сравнений на render. Численное ускорение, CPU/RSS и плавность не измерялись.

Не подменять clipboard ожидаемым текстом.
