# Proteus Modules Dot

Исследования агентных систем и экспериментальные модули для Proteus.

## Цель

Изучать полезные подходы из разных агентов и проверять, как перенести их в Proteus без ослабления гарантий исполнения. Основной язык примеров — Rust; другие языки допустимы для отдельных экспериментов.

## Границы

- Реализации используют публичные contracts и process SDK Proteus. Это отдельные примеры, не изменения Core.
- Полномочия, журнал эффектов, идентичность вызовов и отмена остаются под контролем host.
- Название исходного проекта у примера означает источник идеи, а не полную совместимость с его runtime.
- Для результатов исследований различаются подтверждённый путь в коде, условная гипотеза и выполненная проверка. Измеренное ускорение не заявляется без измерения.
- Каждый пример должен содержать конфигурацию подключения, тесты, точные версии зависимостей и ограничения.

## Статус

Репозиторий инициализирован 25 октября 2026 года. Исследование и первые примеры в работе; готовность, сборка или прохождение тестов пока не заявляются. Изменения модулей будут представлены отдельно для проверки.

Основные проекты: [Proteus Core](https://github.com/Proteus-harness/Proteus-core) и [Proteus Modules](https://github.com/Proteus-harness/Proteus-modules).
