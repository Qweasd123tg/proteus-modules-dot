# Desktop: не разбирать preferences.json второй раз при экспорте

Обычный `preferences.json` разбирается один раз. Проверка встроенных секретов по-прежнему проходит **до** удаления локального состояния окна; затем используется уже проверенный объект. Не меняются чтение файлов, обработка необычного каталога `preferences.json`, проверки JSON/TOML и UTF-8, упаковка, права доступа или импорт архива.

На точном Desktop и Desktop + #477/#479/#483 прошли **7/7** исходных и **10/10** тестов с патчем. Отдельная проверка по **12** синтетических сценариев на каждой основе подтвердила одинаковые байты распакованного TAR либо одинаковую ошибку. Для обычного JSON на **1 040 024 байта** число разборов снизилось **2 → 1**. Вложенный JSON в необычном каталоге сохраняет **2 → 2**; проверены также BOM, невалидный UTF-8, UTF-16 в старой ветке и запрет синтетического секретного поля внутри удаляемого состояния.

Это работа только при явном экспорте настроек, не изменение запуска, памяти Desktop или пользовательских сессий. Реальные настройки, сеть, релиз и замеры времени не использовались.
