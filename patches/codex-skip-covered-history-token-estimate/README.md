# Codex: не пересчитывать весь контекст, если используется предыдущий usage

Когда в истории есть непрозрачный чекпойнт и предыдущий usage ещё покрывает
допустимый префикс, Codex использует этот usage и оценивает только новый
хвост. Раньше он сначала считал запасную оценку по всей истории, а затем
отбрасывал её. Теперь этот лишний проход пропускается.

Без достоверного предыдущего usage запасная оценка сохраняется. Для
истории без чекпойнта она по-прежнему служит нижней границей. Оценка
непокрытого хвоста, даже если в нём есть непрозрачные данные, округление,
минимум и насыщение не меняются. Изменение касается оценки перед
подготовкой контекста, не правил выбора модели или обычного запуска.

Rust 1.95.0: 17/17 в отладочном режиме и 17/17 в оптимизированном. В каждом
режиме пять исходных тестов проверены на обеих версиях точных извлечённых
функций, плюс семь парных проверок. Контракты SDK и вывод JSON заменены
минимальными заглушками. В 1 024 сгенерированных историях оценки совпали.
В синтетическом примере с покрытым значением на 16 МиБ один вызов
форматирования стал не нужен; результат остался 214. Это проверка вызовов,
не измерение фактических аллокаций, памяти процесса или времени.

применение и откат без fuzz и смещений; #514, #517, #521 и #525 меняют
другие файлы. Полная Cargo-сборка, приложение, провайдер и сеть не
запускались.
