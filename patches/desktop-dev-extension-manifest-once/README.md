# Desktop: одна загрузка манифеста для команды и протокола

Предпусковая проверка `scripts/run.py` теперь проверяет команду и протокол расширения по одной версии распарсенного манифеста. Предварительный обход всех пакетов на поддержку возможностей Desktop сохранён. Ошибки идут в прежнем порядке: общий обход возможностей, затем для пакета форма команды, протокол и исполняемый файл. При изменении файла между обходами атомарность не обещается.

На точном Desktop прошло **16/16** исходных и **16/16** тестов с патчем. Для **14 синтетических** манифестов с проверкой Desktop число чтений и разборов снизилось **42 → 28**, проверки исполняемости **14 → 14**. Без проверки Desktop, в том числе в текущем вызове из `scripts/test.py`, осталось **14 → 14**. Пять парных проверок ошибок подтвердили тот же результат и порядок.

Данные и исполняемые файлы были синтетическими; ни один файл не запускался. Это счётчик работы предпусковой проверки разработчика, не замер запуска установленного приложения, RAM, времени или дискового I/O.
