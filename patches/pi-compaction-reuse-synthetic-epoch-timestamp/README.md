# Pi compaction: фиксированная отметка эпохи

При подготовке истории к сжатию Pi получал одну и ту же ISO-строку для каждой
записи через `new Date(0).toISOString()`. Используем эту строку напрямую в том
же поле. Если предыдущее сжатие уже сохранило свой `timestamp`, он по-прежнему
переопределяет значение по умолчанию. Порядок записей, отсечение истории,
сводка и передача сигнала отмены не изменены.

Одна строка в `workflow/pi-runtime/compaction.mjs`. Один и тот же патч
проверен на 331cfc20, с #500 и с #500 + #484. Прямое и обратное применение
без fuzz и смещений, с побайтовой сверкой.

В Node 24.22.3 восемь проверок фактического обработчика и проектора с заглушками
SDK и хоста прошли в шести вариантах. На 125 000 синтетических записей вызовы
конструктора `Date(0)` снизились со 125 000 до нуля. Данные для планировщика и
выход совпали; проверены предыдущие отметки, порог, отмена через неизменный
сигнал, сводка и ошибки. Реальный SDK не запускали; время и память не измеряли.
