# Codex: не копировать выбранное сообщение ответа

В цикле Codex выбранное сообщение используется только для получения
итогового текста. Теперь оно заимствуется из ответа, а не копируется
перед ветвями вызовов инструментов, продолжения и завершения. Сам выбор
и возможная ошибка остаются на прежнем месте, до учёта usage и записи
чекпойнта. Итоговый текст остаётся самостоятельной строкой.

Rust 1.95.0: 8/8 парных проверок в отладочном и 8/8 в оптимизированном
режиме. Выполнены точно извлечённый конец цикла, выбор сообщения и
преобразование в текст. Модель, события, валидация и чекпойнт заменены
локальными заглушками. Сверены 512 сгенерированных сценариев, а также
ошибки и порядок, продолжение, окончание и выбор последнего непустого
текста. В синтетическом ответе с 16 МиБ собственных данных не создаётся
временная копия выбранного сообщения. Это счёт копий в тесте, не
замер памяти или времени приложения.

Один файл `workflow/coding-workflow/src/codex_loop.rs`. Применение и
откат без fuzz и смещений. #525 и #527 меняют другие файлы. Полная
Cargo-сборка, продуктовый процесс, сеть, инструменты и провайдер не
запускались.
