# Analysis: форматировать JSON в одном буфере

Патч к Proteus Desktop Extensions на базе 892f627570369ed60d7205eb0d351c753ec4305f. Вместо временных строк на вложенные значения и поля, векторов и последующих join функция dumps пишет контейнер сразу в один буфер. Старые пробелы и порядок ключей сохраняются; сериализация строк, ключей и скалярных значений использует тот же Serde. Путь для верхнеуровневых скаляров, plain и pretty не изменился.

Патч проверен на применение без пробельных ошибок к точному main и к выбранному дереву Extensions через #459. Штатные тесты пакета Analysis в release (исходный main + патч): 13/13, включая точное сравнение текста для вложенности, порядка ключей, Unicode, эскейпов и -0.0. Только синтетические данные. Составное дерево проверено на применение, но не запускалось. Производительность и память не замеряли.
