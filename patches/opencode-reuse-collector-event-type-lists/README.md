# OpenCode: общие списки типов потоковых событий

Коллектор больше не создаёт списки типов заново при каждом событии.
Три закрытых списка объявлены один раз в модуле; проверки вызываются
в тех же местах и в том же порядке. Чтения `event.type`, обработка
ошибок, разбор содержимого и итоговый ответ не меняются.

Проверен прямой импорт фактического коллектора в Node: семь парных
проверок на 331cfc20, с этим патчем, с #478 и с обоими. На 50 000
синтетических текстовых событий прежний код передал 50 000 разных
массивов в `includes`, новый передал один и тот же массив. Число
проверок осталось прежним. Дельты, метаданные и итог совпали после
нормализации проверенных случайных UUID частей. Это структурная проверка,
не замер памяти, запуска или скорости. SDK, модель и сеть не запускали.

Одна правка в `model/opencode-provider/response.mjs`. #478 меняет поиск
блока, а не диспетчеризацию. Оба порядка применения и отката дали ожидаемые
байты без fuzz; смещения соответствуют размерам независимых правок.
