# R177: OpenCode компактация без массива-обёртки на каждую часть истории

Текст, вложения User и содержимое Assistant теперь добавляются сразу
в итоговые массивы. Не нужны временные пустые и одноэлементные массивы
из callback `flatMap`. Сохраняются порядок ролей и частей, сбор вложений
до текста User, прежний `join("\n")`, поиск результатов инструментов,
ограничение inline media, ошибки и обработка отмены. Индекс из #474,
вызов native prompt и формат контекста не меняются.

Один патч для Modules `331cfc20bbaf821ab07de49868426da29ebdeb64` и той же
основы с #474. Оба порядка наложения и снятие проверены побайтово с fuzz 0;
при совместном наложении учтены только смещения строк.

**12/12** тестов Node 24.22.3 на точном JS с инертным SDK: полный контекст,
ошибки и порядок чтения полей, пустые и разреженные части, старые
checkpoints, последние результаты инструментов и отмена до подготовки.
На синтетических 4 096 сообщениях (16 384 части) трём проекциям больше не
нужны 20 480 промежуточных массивов, возвращаемых callback; сами итоговые
DTO и массивы сохранены. Это подсчёт структуры, не замер времени или
памяти. Реальный SDK, компактация модели, сеть и данные пользователя
не запускались и не читались.
