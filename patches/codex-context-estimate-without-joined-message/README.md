# Codex: считать токены без склейки текста

Для оценки контекста нужен размер строки, а не сама строка. Считаем
байты тех же частей плюс переводы строк между ними, не создавая список
фрагментов и склеенный текст в оценщике. Округление по каждому сообщению,
порядок форматирования, обработка пустых частей и границы числа токенов
сохранены. Там, где нужен сам текст, он по-прежнему склеивается.

Изменение работает при локальной оценке результата сжатия и при
отсутствии переданной оценки входа. Основной workflow часто передаёт
готовую оценку; удалённый оценщик не изменён.

Rust 1.95.0: 6/6 контрольных проверок в отладочной и 6/6 в оптимизированной
сборке, восемь вариантов. На 16 МиБ синтетического текста оценка совпала
без промежуточной склеенной строки. Проверены Unicode, пустые части,
вывод инструментов, ошибки форматирования и числовые границы. Проверялись
точные извлечённые функции с заглушками типов и сериализации, не полный
Cargo-пакет. Время и память не измерялись; сеть и провайдер не запускались.

Один патч для 331cfc20, +#514, +#517 и +#514+#517. Все шесть порядков
применения и их откат проверены побайтово без fuzz.
