# Core: проверять страницы кеша за один проход

Выберите один патч: [stock](stock.patch) для точного Core main 32e56ecb4cc6da324c60dd6ae2da78f3b7e46e7f либо [after454-composed](after454-composed.patch) для набора M150 + #454. Варианты содержат одну и ту же правку; хеши preimage в PREIMAGES.json. Не применять оба и не использовать fuzzy apply при несовпадении.

Проверки количества страниц, строк, байтов, хеша и арифметики сохраняются. Сумму строк теперь считаем в том же проходе, в котором проверяем PageRef, вместо второго обхода. Сумма должна точно совпасть с заголовком, затем выполняется прежняя проверка packed spans. Содержимое кеша, сложение с проверкой, чтения/записи и защитные ограничения не меняются.

Проверка: 8/8 изолированных нативных Rust-тестов для старого и нового валидатора на двух точных базах, с настоящей функцией проверки spans и исходными пределами. Это не сборка Core или Worker и не проверка формата/чтения архивов целиком. Замеры скорости и памяти не проводились.
