# R189: OpenCode Go читает одночастный ответ квоты без копии байтов

После прежнего закрытия reader обычный одночастный `Uint8Array`
декодируется через представление ровно его смещения и длины.
Для нескольких частей, пустого ответа, экзотических, отсоединённых,
разделяемых или изменяемых буферов остаётся прежний `Buffer.concat`.
Размер ответа по-прежнему ограничен 1 МиБ до декодирования.
HTTP, ключ, отмена, ошибки, кэш и формат квоты не изменены.

Один патч для Modules `331cfc20bbaf821ab07de49868426da29ebdeb64`;
наложение и снятие проверены побайтово. **7/7** тестов Node 24.22.3
на реальном коде с инертным fetch и штатным ReadableStream: ненулевые
смещения, разделённый UTF-8, граница, запасные ветки, закрытие reader
и отмена. В тесте с допустимым телом ровно 1 МиБ исчезла одна полная
копия его байтов. Это структурная проверка, не замер скорости или
памяти. Реальные сеть, ключи и модель не использовались.
