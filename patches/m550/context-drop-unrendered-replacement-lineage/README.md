# Context: не держать невидимые связи сообщений в снимке попапа

**Нативная проверка пройдена на точной M420, сборка только `extension-context`.**

`/context` возвращает диагностический отчёт компакции. В действующем Core отчёт уже скрывает `summary`/metadata, но сохраняет `user_message_replacements`, массив пар идентификаторов сообщений. Попап читает только итоговые значения отчёта и никогда не показывает эти пары. Перед сохранением снимка патч освобождает только этот невидимый массив. Ключ свежести, API и его ошибки/пределы, данные отчёта, вывод, протокол и поведение других расширений не меняются. Node и SDK не затронуты.

Изменяется один Rust-файл `packages/context/src/main.rs` на точной M420. После #661 в M420 вошёл только патч #662 для Desktop, исходники Extensions не менялись. Проверены обе Git-структуры и строгие apply/inverse всех 468 записей из независимой композиции.

Через настоящий бинарник `context` проверены два снимка с 8 192 валидными парами UUID, попадания в кэш по прежнему ключу, второй попап, HTTP 503 с прежним деревом, поздний отчёт не-объект и повторное открытие. Все 5 GET на прогон совпали; 7 нативных ответов (17 739 байт) побайтно совпали до/после и с/без измерителя. Пройдено 5 тестов пакета на каждой версии.

При выходе из первого `Context::popup` логически удержанные запрошенные байты относительно входа: **4 510 536 → 29 512** (−4 481 024 байт, ≈4,27 МиБ). Первый дополнительный пик разбора **5 537 170 байт на обеих версиях**. Вариант сокращает удержание в состоянии расширения после разбора; это не замер RSS/PSS, рабочего набора Desktop или ускорения. Точные векторы для семи операций в `receipt.json`.

Дисковые минимумы соблюдены: из 335 949 824 байт в `/tmp` минимум 256 188 416, из 127 758 336 байт в workspace минимум 127 696 896. Последние значения и результат: `disk-guard.json`.

## Воспроизведение

```sh
python3 proof.py --baseline /path/to/Extensions-M406-source.tar.gz \
  --overlay409 /path/to/extensions-M409-changed-files.tar.gz \
  --overlay411 /path/to/extensions-M411-changed-files.tar.gz \
  --overlay414 /path/to/extensions-M414-changed-files.tar.gz \
  --overlay417 /path/to/extensions-M417-changed-files.tar.gz \
  --overlay419 /path/to/extensions-M419-changed-files.tar.gz \
  --desktop420 /path/to/662-source.patch --work /path/to/scratch
```

По умолчанию нет компиляции. Для отдельного native слота добавить `--native --vendor /path/to/vendor --min-free-mib 200` и запускать через `python3 disk-guard.py disk-guard.json python3 proof.py ...` из workspace с `--work /tmp`. Проверка собирает только `extension-context` с заблокированными локальными зависимостями. Нужны Rust 1.95.0, Linux x86_64 и Python 3.12+. Запланированный запас перед запуском: 315 МиБ в /tmp, 105 МиБ в workspace; работа останавливается ниже 200 и 100 МиБ соответственно. Fixture и измеритель не входят в production patch.
