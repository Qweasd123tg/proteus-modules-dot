# Files: передать строки и меню без потери компактности

Панель забирает уже готовые строки и JSON-меню. В версиях до патча `json!` сначала копировал их, но одновременно уплотнял вложенные карты. Именно это не учёл отвергнутый W18: передача готовых карт ухудшила удерживаемую память. Теперь вложенные карты пересобираются с точной вместимостью по числу полей, но ключи и значения перемещаются без глубокого клона. Массивы ужимаются на месте; исходный порядок полей сохраняется.

Изменяется один native-файл `packages/files/src/main.rs` на точной M416 (Extensions совпадает с M414). Это панель и её демо, не кэш предпросмотра #654. Правила списка, порядок и payload действий/подтверждений, ограничения API и протокол не меняются. SDK и Node не затронуты.

## Проверка

- Точный apply/inverse всех 468 записей запечатанной базы. 43 locked native теста на каждой версии.
- Настоящий `files`: 6 побайтово одинаковых ответов (8 762 983 байта), обе версии с измерителем и без него. Синтетический read-only HTTP, 1000 входных записей, усечённый листинг, lookahead 64, вложенные папки, раскрытие/сворачивание, повторный показ, меню и отдельно встроенное демо. Действия с записью не выполнялись.
- В трёх больших тёплых проходах удерживаемые байты совпали точно; пиковый прирост в каждом из пяти проходов не вырос. Ниже первый тёплый проход в `Files::panel`, только логические layout bytes:

| Измерение | До | После |
| --- | ---: | ---: |
| Запрошенные alloc/realloc bytes | 27 269 818 | 24 854 947 |
| Логические живые байты при возврате | 9 980 659 | 9 980 659 |
| Дополнительный логический пик | 10 214 213 | 10 047 705 |

Это учёт Rust-аллокатора (1.95.0, dev без отладочных символов), не RSS/PSS приложения и не замер задержки. Порог места соблюдён на единственной разрешённой последовательной сборке; её временные файлы автоматически удалились.

## Воспроизведение

```sh
python3 proof.py --baseline /path/to/Extensions-M406-source.tar.gz \
  --overlay409 /path/to/extensions-M409-changed-files.tar.gz \
  --overlay411 /path/to/extensions-M411-changed-files.tar.gz \
  --overlay414 /path/to/extensions-M414-changed-files.tar.gz --work /path/to/scratch
```

По умолчанию только проверка исходников. `--native --vendor /path/to/vendor` запускает локальную locked проверку Linux x86_64/Rust 1.95.0 с parity и gate по удержанию/пику. Fixture и измеритель не входят в исходный патч.
