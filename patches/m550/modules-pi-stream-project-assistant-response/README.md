# Pi: project multi-message replies directly into one array

Convert each response row and append its content to the final Pi answer before moving to the next row. Previously the adapter first retained an array of every projected row and then flattened them. The single-message case still reuses its projected content array; scalar rows, ordering, cross-row tool names and projection errors remain unchanged for ordinary decoded inputs.

The paired checks exercise the exact shared projection and context helper only. They do not run the Pi SDK, use a model or measure Proteus time or memory. The current Modules revision and Desktop pin match the preimage. The immutable #742 verification packet and its unchanged source selector corroborate this leaf at M500; this delivery does not reproduce the complete M500 inventory.
