# Avoid a second copy in plain code blocks

Construct the retained SharedString directly from the borrowed text instead of an intermediate String. Applies only to plain code and missing-provider fallback constructors and setters.

Apply `source.patch` to the two exact Desktop preimages in `receipt.json`. In both creation routes the scoped allocator peak dropped by one payload length, approximately 2 MiB for a 2 MiB block, with the same retained bytes and update behavior. All 16 native scenarios passed. This is not a whole-app memory measurement.
