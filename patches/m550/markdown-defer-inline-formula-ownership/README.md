# Markdown: формулы не копируют до решения о видимости

Пакет хранит исходные диапазоны parser-approved формул как ссылки на прежний неизменяемый текст. Он больше не выделяет отдельные строки для сырой формулы и для её HTML-подстановки. При замене placeholder HTML-экранирование пишет прямо в итоговую строку, а JSON-виджет создаётся только для реально встреченного ID. Пропуски убираются на месте; порядок виджетов остаётся исходным, даже если HTML переносит сноски.

Затронут только `packages/markdown-render/src/inlines.rs` точной базы M406 после #647. Не меняются guard Markdown, правила raw HTML, байтовый предел 32 KiB для формулы, максимум 256, регистрации провайдеров, native wire или downstream-рендереры. Node не менялся.

## Нативная проверка

- 52 unit + 3 package subprocess теста на каждую сборку.
- Независимый реальный stdin/stdout `markdown-render`: 9 ответов, 7 063 835 байт, полное byte-for-byte сравнение. Проверены большой документ, идентичный повтор (без повторного рендера), правка одной формулы, лимит 32 KiB и на байт больше, 258 кандидатов/256 видимых, повторно адресованная и скрытые сноски, исходный escaped dollar, currency, raw HTML, code/image alt, переход на отключённого провайдера и открытие с Tex после close. Синтетический fixture не запускает детей TeX или Node.
- Измеритель в настоящем `inlines::render`, включая расширение HTML: Rust 1.95.0 dev без отладочных символов, запросы аллокатора и логические живые layout bytes относительно входа в функцию.

| Случай | До | После |
| --- | ---: | ---: |
| Пик рендера 64 больших формул, исходный и отредактированный ввод | 5 807 187 | 4 651 943 |
| Запрошенные alloc/realloc bytes тех же рендеров | 19 949 757 | 17 638 338 |
| Пик фазы HTML со скрытыми сносками, от входа в рендер | 109 730 | 36 752 |
| Пик рендера на пределе 256 формул | 786 456 | 786 456 |

Пик HTML-сборки на пределе 256 формул также снизился (172 065 → 163 225). Контроль без провайдера совпадает по всем счётчикам. Это не оценка RSS/PSS, задержки или памяти всего Proteus; измерение не включает удержание входного файла до вызова, другие потоки и низкоуровневые накладные расходы аллокатора.

## Воспроизведение

```sh
python3 proof.py --baseline /path/to/Extensions-M406-source.tar.gz --vendor /path/to/vendor --work /path/to/scratch
```

Linux x86_64, Rust 1.95.0, Python 3.12+. Проверяются точные SHA базы и патча, неизменный lock, locked сборка, обе стороны настоящего wire и строгий обратный патч (все 468 записей). Инструментирование и fixture не входят в продукт.
