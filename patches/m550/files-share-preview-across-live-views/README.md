# Files: один предпросмотр для кэша и всех вкладок

Files раньше держал JSON-ответ предпросмотра и создавал ещё одну строку целиком для каждой видимой вкладки. Теперь ответ сразу отдаёт собственную строку телу виджета, а кэш и все однотипные вкладки держат ссылки на один неизменяемый виджет. Заголовок и его действия остаются собственными у каждого вида. SDK использует тот же сериализуемый `fill` для общего корня и для fallback, без изменения формата.

Ключ файла/режима, активность и интервал перепроверки, открытые владельцы, порядок GET и инвалидирование не меняются. Отказ чтения и двоичное/нестроковое содержимое проходят прежнюю ветку. Источник и лимит сервера не менялись. Изменены четыре native-файла Files/SDK на точной базе M411; Node не затронут.

## Проверка

- В исходном рабочем дереве с точной композицией M411 собраны обе стороны. База: 340 workspace-тестов, один ранее наблюдённый Linux Mermaid PID-тест исключён. С патчем: 43 теста Files, 73 теста SDK и один doctest. Полный workspace с патчем не повторялся из-за общего дискового ограничения.
- В настоящем `files` с синтетическим read-only HTTP: 13 byte-for-byte ответов (5 290 227 байт), без подмены процесса. Три открытые вкладки одного файла, два режима и возврат в кэшированный режим, закрытие одного владельца и замена аргумента другого, финальное освобождение и новый GET, HTTP-отказ, malformed binary и рефетч после события. SDK отдельно проверяет равный fallback и сохранение той же ссылки до замены вида.
- В исходных точных сборках проверены обе версии wire с измерителем и без него. Независимая реконструкция M411 из поставочных архивов повторила только точный apply/inverse всех 468 записей; на ней повторной компиляции не было.

## Память

Фиксированная синтетическая превью-строка фактически 480 000 UTF‑8 байт. Учёт в реальном `Files::render` вместе с сериализацией и сохранением дерева для fallback (Rust 1.95.0, dev без отладочных символов).

| Прирост логически живых layout bytes | До | После |
| --- | ---: | ---: |
| Три последовательных открытия одного файла | 1 940 713 | 497 185 |
| Открытие ещё одной вкладки после первой | 485 967 | 4 698 |

Первый пик разбора HTTP в обеих сборках остался 1 485 103 байта по этому счётчику. На новых маленьких телах и заголовках есть цена контейнера `Arc`; для больших одинаковых превью он заменяет полный клон. Измерение не является RSS/PSS процесса, памятью GUI или сравнением задержек.

## Воспроизведение

```sh
python3 proof.py --baseline /path/to/Extensions-M406-source.tar.gz \
  --overlay409 /path/to/extensions-M409-changed-files.tar.gz \
  --overlay411 /path/to/extensions-M411-changed-files.tar.gz \
  --vendor /path/to/vendor --work /path/to/scratch
```

Linux x86_64, Rust 1.95.0, Python 3.12+. Проверяются точные SHA входов и патча, native тесты Files/SDK, сырой wire и обратимость. `--source-only` проверяет только strict apply/inverse; `--workspace` дополнительно выбирает полный locked workspace, кроме отдельно указанного baseline PID-теста. Инструментирование не входит в production patch.
