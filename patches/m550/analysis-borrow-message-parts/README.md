# Analysis: не копировать части сообщения до их объединения

Простой `Text` теперь до конечного join заимствует исходную строку отчёта с обрезанными краями. При форматировании `ToolResult` строковый output/error заимствуется до сборки подписи вместо предварительного клона. `FileRef` собирает путь, перевод строки и содержимое в один owned фрагмент, а не через промежуточный клон и отдельную отформатированную строку. Результат интерфейса по-прежнему полностью owned; отчёт не удерживается дополнительно. Это этап форматирования сообщения, а не изменение жизненного цикла отчёта (#644).

Затронут только `packages/analysis/src/text.rs` точной базы M409 после #649. Сохраняются выбор truthy output/error, обрезка только предусмотренных пробелов, переносы FileRef, формат Python-подобных скаляров/контейнеров, исходный порядок полей, пропуск reasoning, pretty fallback и все границы API/IPC. Нет изменений SDK, протокола или Node.

## Доказательство

- 19 locked тестов на каждой версии.
- Живой `analysis` с read-only loopback отчётами: пять точных ответов (8 573 311 байт), исходная и повторная сборка составного model-message с Text, FileRef, ToolResult, Reasoning, Image, ToolCall и неизвестным типом, скалярные и структурные fallback, пустой текст, свёрнутый шаг, отказ API с прежним деревом, close/reopen. Проверены байты disclosure и порядок HTTP.
- Реальный `message_text` внутри обоих больших native ответов: два одинаковых парных результата на 1 846 086 байтах готового текста.

| Измерение в `message_text` | До | После |
| --- | ---: | ---: |
| Запрошенные alloc/realloc bytes | 5 174 337 | 2 808 264 |
| Пиковый логический прирост живых layout bytes | 3 692 265 | 2 808 251 |
| Логически живые байты возвращаемого результата | 1 846 086 | 1 846 086 |

Отдельные контролы односоставного текста и raw-JSON fallback совпали по всем счётчикам; остальные маленькие пути не увеличили запросы/пик. Измеритель Rust 1.95.0 dev без отладочных символов измеряет только функцию форматирования, не включает начатые до неё HTTP/JSON/UI и не измеряет RSS/PSS либо задержку.
