# Mermaid SVG: capture inline style and color while decoding attributes

Remember the first decoded style and color during the existing attribute pass. Do not scan the collected attributes again to find them. Keep every input attribute in order and leave CSS precedence, aliases, inheritance, escaping and output generation unchanged.

The exact local SVG helper passed 17 paired checks in both public theme entry paths. A synthetic 1,536-element input under the producer's configured byte limit made 2,688 fewer attribute searches with identical output. A larger direct-helper stress fixture also matched. These are search counts, not timed render or application measurements. No production renderer, vendor runtime or Desktop app was exercised.
