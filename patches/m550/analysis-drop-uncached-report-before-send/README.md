# Analysis: отпустить отчёт до блокирующей отправки

Analysis преобразует ответ `/analysis` в самостоятельное дерево вида. Ответ, который не умещается в 8 MiB бюджет общего кэша Analytics, принадлежит только этому рендеру. Раньше он жил до конца рендера, в том числе пока клиент не успевал читать stdout. Теперь ссылка на отчёт заканчивает жизнь после построения дерева, до синхронного `host.show`. Допущенный в кэш ответ остаётся в кэше. Без изменений endpoint, порядка чтения, TTL, обоих лимитов HTTP/кэша, wire и fallback.

## Нативное доказательство

- Точный M401 Extensions tree `e5ddf8cb02687059420e26d30f52255cca37e294` включает #641. #643 меняет только Core; Integration подтверждает, что все 468 записей Extensions побайтово те же, что в её полном архиве M400.
- Настоящий `analysis` и синтетический loopback HTTP: 7 побайтово одинаковых ответов (5 353 639 байт). Получение ответа больше кэш-бюджета, повторный запрос после выбора ранее скрытого шага, отказ `/sessions`, превышение 10 MiB HTTP, последнее удачное дерево при обоих отказах, повторное чтение из кэша без HTTP, закрытие и новый запрос.
- В инструментированном запуске на Linux stdout намеренно не читается, пока основной поток дочернего процесса не наблюдается в `pipe_write` для каждого ответа. Деаллокация измерена прямо перед `host.show` в реальном обработчике, отдельно от чтения/отправки.

| Прирост логических живых layout bytes перед записью | До | После |
| --- | ---: | ---: |
| Первый большой ответ, не попавший в кэш | 9 542 827 | 498 365 |
| Второй большой ответ, после выбора шага | 10 243 937 | 1 199 475 |

В этой паре запусков оба раза удерживалось на **9 044 462 байта меньше** перед записью. Независимый replay требует не менее 9 000 000 байт выигрыша; счётчики HTTP-соединения могут сдвинуть локальную выборку на несколько сотен байт. Для пиков разбора/построения, запросов аллокатора и контролей с HTTP задан малый допуск; контрольный cache hit без HTTP совпадает точно. Это профиль нативного обработчика (Rust 1.95.0, debug без отладочных символов), не освобождённый RSS/PSS всего процесса и не обещание общего ускорения.

## Воспроизведение

На Linux с читаемым `/proc/<pid>/wchan`, Rust 1.95.0, Python 3.12+ и проверенной локальной Cargo vendor directory:

```sh
python3 proof.py --baseline /path/to/Extensions-M400-source.tar.gz --vendor /path/to/vendor --work /path/to/scratch
```

Скрипт проверяет SHA, собирает обе стороны без сети (19 тестов на сторону), запускает настоящий бинарник с тем же HTTP/wire fixture, временно вставляет измеритель и проверяет строгий обратный патч до всех 468 исходных записей. Инструментирование не входит в исходный патч.
