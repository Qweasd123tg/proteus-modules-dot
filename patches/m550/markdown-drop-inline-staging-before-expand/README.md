# Markdown: освободить временную строку до расширения HTML

GFM получает временную строку с плейсхолдерами вместо исходных формул. После компиляции расширение читает только скомпилированный HTML и исходные срезы. Теперь временная строка освобождается сразу после GFM, а не удерживается поверх растущих HTML и inline-виджетов. Правила распознавания, исходные формулы, виды экранирования, пределы и нативный протокол не меняются. Это отдельная граница жизни буфера, уже существовавшего до #649.

Изменяется только `packages/markdown-render/src/inlines.rs` на точной M417 после #659. Проверены SHA и строгий apply/inverse всех 468 записей. Node, SDK и сборочный lock не затронуты.

## Проверка

- 52 unit и 3 package subprocess теста на обеих версиях.
- Настоящий `markdown-render`, 9 побайтово одинаковых IPC-ответов (7 063 835 байт) с измерителем и без. Два больших рендера с правкой формул, попадание в кэш, 32 KiB и +1, максимум 256, скрытые сноски, escaped dollar, raw HTML, отключение/смена провайдера и повторное открытие.
- Парные измерения только в `inlines::render`: Rust 1.95.0 dev, запрошенные layout bytes; не PSS/RSS, не задержка и не общесистемный пик.

| Два независимых больших рендера | До | После |
| --- | ---: | ---: |
| Пик логически живых байт функции | 4 651 943 | 3 498 173 |
| Логически живые байты на входе в расширение HTML | 1 159 223 | 5 453 |
| Логически живые байты после возврата результата | 3 493 565 | 3 493 565 |
| Запрошенные alloc/realloc bytes | 17 638 338 | 17 638 338 |

Разница пиков в обоих больших рендерах **1 153 770 байт**. Во всех измеренных случаях одинаковы запросы и память результата, ни один локальный пик не вырос; на малых формах может доминировать более ранний разбор, и общий пик тогда не меняется. Оба порога места выдержаны на единственной последовательной сборке; временная сборка автоматически очищена.

## Воспроизведение

```sh
python3 proof.py --baseline /path/to/Extensions-M406-source.tar.gz \
  --overlay409 /path/to/extensions-M409-changed-files.tar.gz \
  --overlay411 /path/to/extensions-M411-changed-files.tar.gz \
  --overlay414 /path/to/extensions-M414-changed-files.tar.gz \
  --overlay417 /path/to/extensions-M417-changed-files.tar.gz --work /path/to/scratch
```

По умолчанию без компиляции. `--native --vendor /path/to/vendor` запускает обе locked сборки и проверку эффекта на Linux x86_64/Rust 1.95.0/Python 3.12+. Fixture и измеритель не входят в продукт.
