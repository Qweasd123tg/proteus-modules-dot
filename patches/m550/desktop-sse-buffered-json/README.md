# Desktop: decode a complete buffered Proteus SSE record without a line copy

One patch to `src/api/mod.rs` on exact Desktop M368. The startup route is the Proteus HTTP SSE session, not Codex. Core's native encoder already provides `event: output\ndata: <JSON>\n\n`. When that record is wholly in the Desktop's existing `BufReader`, parse its borrowed payload and consume exactly the two-line boundary without creating a temporary full-length line. The helper inspects only resident bytes; it does not perform any reads or change limits. The suffix check is deliberately conservative: an invalid/partial/multiline/noncanonical boundary goes through the stock reader. Even a complete first record can fall back if later buffered bytes are partial.

The scoped proof lifts the exact M368 Core encoder and Desktop receiver functions and builds the **full native M368 Contracts** crate. Desktop's pinned `app_protocol.rs`, `live.rs`, and `transcript.rs` match these files byte-for-byte. The source audit follows the prepared workspace startup stream through `Api::events`, the receiver pump, and the pre-render batch. No network/GUI timing or process RSS was measured. Controlled `Read` cuts model delivery fragmentation, not an HTTP socket benchmark.

On the native encoder's 7,894-byte wire fixture, the first snapshot keeps the same 50 resident rows of a 50,000-row archive, cursor, revision, order and text. With the event available together in the buffer, the measured receiver used **three fewer allocation/reallocation calls and 7,903 fewer requested bytes** in both JSON map modes (default: 275→272, 131,032→123,129 bytes). The 212,694-byte fragmented first page used exactly the same allocations/bytes as stock. The fixture is not a claim that all real first pages fit the default buffer. Both arms pass 543 edge controls including split UTF-8 input, CRLF, continuation, interruption, malformed framing, heartbeat, response errors, EOF and ordering of subsequent events.

Run `python3 verify.py [--vendor /path/to/cargo-vendor]` with Rust 1.95.0; the optional vendor directory makes tests offline. The capsule and receipts include immutable source/blob pins and dependency checksums. `composition.json` records exact forward/inverse composition with the earlier #597, #602 and #609 changes in both the candidate-first and candidate-last orders. The candidate does not touch their files.

Historical #400 already reuses an owned line (the unchanged fallback here). It is not this no-copy branch: the proof baseline contains #400, and composition records its actual reverse/reapplication to the exact baseline leaf.
