# Desktop transcript ingestion: two independent proposals
Both diffs target `src/transcript/mod.rs` at canonical M350 (blob 9088044b2eaa79efa868c3603229b526683a7658). The exact path is also pinned Desktop main f8cc401 plus already-counted #522. Do not count #522 again. Each diff works alone; apply together in either order with regular git apply. Other M350 paths are untouched.

- `borrowed.patch`: the lookup indexes across a snapshot reset or appended page borrow tool/child identifiers instead of cloning every String. Identity precedence stays message+role, then tool, then child. A Cell holds the old row only until its first reset match. Duplicate resets still select the last old winner once; pages still reuse the first live winner without consumption. Cell is scoped to one reset. Incoming and old rows stay alive only as required by the original ownership model.
- `local.patch`: during one reset, the backwards timestamp fallback drops the unmatchable suffix of the previous snapshot once, without allocating a new index. Only rows lacking a message ID and carrying a timestamp can be a candidate. Older matching rows, including rows with a tool ID, are still eligible. Worst case with eligible rows near the tail need not improve (one extra eligibility check per search): not a blanket claim of linear complexity.
