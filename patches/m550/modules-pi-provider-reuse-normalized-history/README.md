# Pi model adapter: reuse the history array when adding its system message

Keep the established projection and tool mapping before building the optional leading system message with Pi's public helper. Add this message to the private projected array, then use the same public normalizer with a messages-only input. When there is no leading message, the array is not moved.

The exact local v14 adapter passed 16 paired controls on owner and scoped helper versions, with inert runtime and the two pinned pure transcript helper bodies. With 6,144 synthetic history records and tools plus a prompt, the normalized output was identical without the extra 6,145-entry history array. This is a logical array check, not installed Pi execution, measured bytes or application timing.

The patch applies to the Pi model provider when selected, not to standalone Pi tools or profiles using another model provider.
