# R160 — OpenCode: пропустить индекс имён, если он не нужен

Один патч для stock Modules `9469e3b12529d08b1f4a76882693e2065e842c51` и
выбранной основы #452 → #462 → #465 → #466 → #467 → #468 → #469 → #470.
Изменён только `model/opencode-provider/messages.mjs` (до патча байты
одинаковы на обеих основах).

Для истории без ToolResult и без чтения изображения из файла больше
не нужен отдельный обход истории и Map имён ToolCall. Если имя понадобится,
при первом ToolResult выполняется **тот же полный проход**: видны вызовы
после результата и последнее имя при повторном ID. Незаданный ID сохраняет
fallback `message.name`; пустое найденное имя не превращается в fallback.
При первом изображении с file path остаётся прежний полный проход **до
первого чтения**; inline изображение не читает диск. Функция чтения,
path и исходный AbortSignal остаются теми же.

Core передаёт v14 каноническую принадлежащую запросу JSON-копию: массив
сообщений с массивами частей и enum payload. В дополнительном обходе
не выполнялись I/O или внешняя отправка; pinned `Media.Asset` конструктор
из inline bytes/base64 только формирует объект. Для raw сообщений с
`parts` не-массивом и правдоподобным ToolCall без `call` сохраняется отказ.
Диагностика/порядок нескольких ошибок для неканонического прямого ввода
могут отличаться, но удалённый проход не позволяет открыть файл раньше
обнаружения этих нарушений. Порядок для валидной канонической истории,
проверки формы/выбора инструмента и Go session_id, маршрутизация и итоговый
DTO не меняются.

Проверено: exact apply/reverse 0 fuzz на обеих основах, byte readback,
Node syntax; **8/8** VM тестов с точными исходниками converter и context
плюс инертным SDK, форматированием и file reader. Покрыты роли и поля DTO,
future/repeated ToolCall, nullish fallback, ошибки без native dispatch,
обычное/inline/file-изображение, отмена и malformed/потенциальное чтение.
В обычной пятиэлементной фикстуре без ToolResult и file read: 1→0 Map и
2→1 обход истории (10→5 посещений сообщений). Это не число всех
проверок свойств, не замер времени или памяти. Реальные SDK, filesystem
image read, сеть и inference не запускались.
