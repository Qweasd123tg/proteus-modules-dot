# R156 — OpenCode: использовать загруженный seed при сбое live-каталога

Один изменённый файл: `model/opencode-provider/runtime.mjs`. Нужен #465;
`composed.patch` не предназначен для stock без локального seed. Патч проверен
на точной основе #452 → #462 → #465 → #466 → #467. #466/#467 не меняют
`runtime.mjs`. Применять с `-p1 --fuzz=0`.

Для Go/Zen без явного `models_file`/`models_url` и без injected loader:
если уже проверенный, нормализованный и помещённый в бюджет seed есть в памяти
**в начале** нового live lookup, native `refresh(false)` ещё выполняется с
прежним запросом и политикой SDK. Только в этом scope отключается полный SDK
bundle как fallback. Точный ModelsDev 2.0.22 записывает успешно разобранное
тело публичного каталога в свежий transient KV с ключом `models-dev:catalog`.
Отмечается факт записи, не копируется её содержимое. Успешное пустое тело,
ответ с другим provider и ошибки его нормализации остаются авторитетными.
Без записи и без результата get, при живом signal, возвращается тот же
выбранный пакетный provider, без нового чтения и нормализации.

Если lookup стартовал без seed, в том числе после отдельного respawn или
если seed загрузился параллельно позднее, остаётся обычный fallback и ничего
дополнительно не загружается этим изменением. Явные источники (даже пустые),
другие provider, injected loader, live success, TTL, отмена и ограничения
оставлены прежними. Не меняются wire, auth, quota, сеть или права. Нет
постоянного last-good и нового фонового refresh.

Проверены exact apply/reverse dry-run 0 fuzz и byte readback, Node syntax и
**10/10** изолированных VM тестов. Выполнялись точные runtime/seed loader
и реальные локальные seed-файлы Go/Zen. SDK transport/decoder/normalizer были
инертными, с проверенной source-последовательностью refresh → transient KV →
get. Проверены parity picker в fallback, успешный/пустой/чужой/ошибочный live
ответ, key scope, холодный/поздний seed, override/injection, TTL и отмена
одного/всех читателей. Реальные SDK, startup, сеть, память и задержка не
проверялись. Патч избегает только глобальной **нормализации и удержания**
полного bundled fallback в этой ветке, а не bundle ESM текста или всего SDK.
