# Codex: не копировать готовый текст перед склейкой истории

Подготовка истории к сжатию теперь заимствует готовый текст из частей
Text, Context, Patch и ReasoningSummary. До этого каждая такая строка
копировалась перед склейкой. Итоговая строка остаётся самостоятельной.
Форматирование других частей, порядок, пропуск пустых строк и правила
усечения не меняются.

Rust 1.95.0: 5/5 проверок в отладочной и 5/5 в оптимизированной сборке.
Проверены точные извлечённые функции и вызов удалённого усечения на базе
331cfc20 и с #514. В синтетическом примере с 16 МиБ текста четыре
промежуточные копии заменены ссылками на исходные строки; итог побайтово
совпал. Типы из SDK и сериализация JSON заменены заглушками, а функция
форматирования результата инструмента взята из точного SDK.
Полный Cargo, провайдер, сеть и продуктовый процесс не запускались.
Время и память не измерялись.

Один файл `hook/codex-context-preparation/src/history.rs`: применение
и откат в обоих порядках с #514 сходятся побайтово, без fuzz и смещений.
