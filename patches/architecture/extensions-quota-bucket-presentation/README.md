# Share quota display status classification

Use one interpretation of reported quota flags in the badge, tooltip and
detail cards. Compute the badge's aggregate status during the existing
summary pass. Informational buckets still show their flags in details but
cannot control the badge. Provider requests and actual quota rules do not
change.

Use source.patch on pinned Extensions or source-after-stack.patch on the
cumulative tree. All focused native fixtures are synthetic.
