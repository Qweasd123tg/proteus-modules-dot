# Codex: искать границы усечения без обхода всей строки

При сжатии истории длинный сохранённый текст пользователя усекается с
двух сторон от удаляемой середины. Чтобы найти границы UTF-8, прежний код
просматривал все символы; теперь используются две стандартные операции
поиска ближайшей границы. Бюджет, расчёт числа удалённых токенов и сам
маркер не меняются. Это границы скалярных символов UTF-8, не графем.

Три функции извлечены из точных файлов без переписывания и проверены
в Rust 1.95.0: 5/5 в отладочной и 5/5 в оптимизированной сборке. Совпали
байты результата для всех скалярных символов Unicode, смешанных строк,
крайних бюджетов, пересекающихся окон и строки 16 777 220 байт. Для поиска
границ больше не нужно обходить её 6 710 888 символов; запись сохранённого
текста остаётся. Это не замер скорости или памяти. Полная Cargo-сборка,
провайдер и продуктовый процесс не запускались.

Один блок в `hook/codex-context-preparation/src/budget.rs`. Применение и
откат на 331cfc20 сверены побайтово, без fuzz и смещений.
