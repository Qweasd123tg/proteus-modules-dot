# R187: Claude hook читает небольшой JSON без буфера на 1 МиБ

`readJson` раньше выделял и заполнял нулями 1 048 577 байт для любого
файла. Теперь размер уже открытого файла лишь подсказывает начальный
размер буфера: не меньше 4 КиБ и не больше старого предела. При росте
файла буфер расширяется по мере чтения. И чрезмерный размер в stat,
и усечение после stat по-прежнему оцениваются по фактически
прочитанным байтам, а не по метаданным.

Не изменились флаги открытия, проверка обычного файла на том же
дескрипторе, обработка коротких чтений, проба одного байта за 1 МиБ,
закрытие и разбор UTF-8/JSON. Перенос и запуск hooks не менялись.
Один патч для Modules `331cfc20bbaf821ab07de49868426da29ebdeb64`;
наложение и снятие проверены побайтово.

**8/8** тестов Node 24.22.3: реальные синтетические файлы и подставной
дескриптор для коротких чтений, изменения размера, границы и ошибок.
У стабильного файла на 1 024 байта первая ёмкость снизилась с 1 048 577
до 4 096 байт. Это размер буфера в тесте, не замер времени, RSS или PSS.
При росте файла старый и новый буферы могут временно перекрываться.
Настройки пользователя, команды hooks и SDK не читались и не запускались.
