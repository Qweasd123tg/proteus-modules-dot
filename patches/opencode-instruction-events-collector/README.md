# R179: OpenCode собирает события инструкций без обёрток на каждую запись

Перед модельным запросом `projectInstructions` больше не вызывает
`instructionEvents([message])` для каждой записи истории. Сборщик добавляет
события непосредственно в итоговый список или в один переиспользуемый
буфер текущей записи. Сохранены полный предварительный фильтр, проверка
всех частей записи до её проекции, порядок «метаданные, затем части»,
номера событий, SHA-идентификаторы и исключение повторных путей.
Вызывающие стороны, компактация и права доступа не изменены.

Один патч для Modules `331cfc20bbaf821ab07de49868426da29ebdeb64`. Наложение
и снятие проверены побайтово также с точными #474 и #486: файл компактации
не изменился. Для некорректных входов вроде неитерируемых исходных
метаданных сохраняются отказ и его порядок; текст TypeError движка может
отличаться. Разреженные массивы, скалярные результаты инструментов
и вложенные значения сохраняют прежний результат.

**8/8** тестов Node 24.22.3: точный JS, настоящий SHA-256, инертный SDK.
На 16 384 синтетических записях без событий выход совпал побайтово.
Подсчёт показал, что четыре вида массивов на запись и пустые массивы
на каждую её часть больше не создаются; один буфер остаётся на весь
вызов. Это структурная проверка, не замер времени или памяти. Настоящие
SDK, модель, инструменты и сеть не запускались.
